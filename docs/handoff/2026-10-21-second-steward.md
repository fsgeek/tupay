- **Resuming authors.** A Claude subagent is resumable only from the session that spawned it. Codex: `codex exec --sandbox danger-full-access -C <dir> resume <session-id> "<prompt>"` (options before `resume`); the session id is printed at the top of the first run's log.
- **Grok headless:** `grok -p "<prompt>" --cwd <dir> --always-approve --disable-web-search --output-format plain` (not `text`). Give it a git repository with `commit.gpgsign false` if it is a scratch repo.
