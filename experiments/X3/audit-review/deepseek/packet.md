===== the registration's audit paragraph (experiments/X3-prereg.md) =====
3. **The support audit is registered** (practice since the replay): every model PASS is scored only after the steward has run a probe showing the checked space contains the schedule's needed reach. A passed audit is permission to score, one necessary condition met; it does not make the PASS evidence that the property holds beyond the checked space (Yupi, plaza seq 149). **Needed reach is registered**, per schedule, in `experiments/X3/reach.md`, generated from the schedule text by `scripts/steward/reach-table.py` (floors for lease and configuration size, clients, grants, requests, epochs, crashes, amnesic restarts, clock steps, largest step in ticks, terms), so it cannot be fitted to an arm. **Probe method**, per model side: for each schedule, a TLC run at the author's stated bounds with an invariant negating a state that meets every floor of that row (for example, "no state has a committed epoch k and an incarnation i and a clock offset of t ticks"); the audit passes if TLC reports that invariant violated. **A failed audit** makes the schedule "no support" in 1(a), counted as not PASS, and its mutation unassessable in 1(b). A side that does not model a quantity a row needs (no clock, no incarnation) is "vacuous by design" for that schedule: reported, not PASS.

`probe.py` builds `Floor` as the conjunction of one conjunct per nonzero column of the schedule's reach row, using

## How each column is counted

Kinds: **structural** means a compiled constant. `probe.py` checks it against the side's compiler output (A:
`meta["processes"]`, R: `meta["lease"/"config"/"clients"]`) before TLC runs, and a miss is NO-SUPPORT without a
run. It is also conjoined in `Floor`, where it is constant-level and costs nothing. **state** means a model variable.
**step** means the count comes from the schedule position. In both models `pc` is the index of the next schedule
step, and a step at index `i < pc` has been taken: its action fired in the model, through A's `ScheduleStep`
(`pc' = pc + 1`, Lease.tla:1186) or R's `Take` (Lease.tla:913). **vacuous** means the model has no state for the
quantity.

## Judgement calls

1. **Conjunction at one state.** The registered method needs one state that meets every floor. Every expression
   above is monotone along a run (history variables, step counts), except three. The `leader`/`role` disjunct of
   terms is volatile. `inc` is monotone, but A and R reset `promised`/`term` on amnesia, which is why terms is read
   from grant history or a current leader and not from `promised`/`term` alone. A's `off` is not monotone and is
   not used (item 3).
2. **Terms means a leader (grantor) term k existed.** It is read as a grant issued in term ≥ k, or a node that is
   currently leader at term ≥ k. A bare `term[n] >= k` was rejected for R because `SpurFail` (:360, `BecomeCand`
   :319) raises a term with no leader. A's `promised` would be equivalent in A, since it is raised only to an
   elected term, but it is reset on amnesia. A schedule with a terms floor of 2 and no request that both ends with
   no leader would be judged by the leader disjunct only. Of the 63 rows, H11 is the only one with a terms floor
   of 2 and zero grants.
3. **Max ticks is counted by step position in A, not by `off`.** `off[p]` accumulates: P44 steps the grantor by
   −1 and then +3 ticks, so `off` never reaches 3 although a 3-tick step is taken. The floor asks for the largest
   single step, which is the `s` of a taken clock step. Taking that step is what changes `off`
   (`ClockStep`, `off' = off + s`), so in A the step is the modelled clock.
4. **Crashes, reconfig sent (A) and clock steps are counted by step position.** No state variable counts them,
   because a crash is undone by a restart and requests are consumed. A taken step is a reached model transition,
   since every step is guarded by its trigger and its own enabling condition. A floor that needs the schedule to
   get that far can therefore fail.
5. **R's clock is vacuous, not step-counted.** R takes the clock step but has no clock state. Departure 3 names
   "no clock" as the example of vacuous by design. `audit.sh` labels these rows VACUOUS and reports the step-position
   result beside the label. That result is not presented as SUPPORT.
6. **R's deadlock check is off in the probe.** The author's `safety.cfg` has `CHECK_DEADLOCK TRUE`, which is the
   liveness terminal form. Left on, it would stop the search at the first stuck state, which is not a reach
   question. A's runs already pass `-deadlock`, which turns the check off. For arm R, the full-space count from a
   NO-SUPPORT run (for example, P63 MUTANT: 638,457 distinct) is therefore larger than the count from the author's
   safety run when that run stopped at a FAIL (P63: 24,725, FAIL C3.4).
7. **R uses `SpecL`, not `Spec`.** `SpecL` is the specification of the author's checking run. It adds only `Idle`
   stuttering, so the set of reachable states is the same.
8. **Floors are ≥.** A state that exceeds a floor (more grants, a higher epoch) meets it.

## Anti-theater (`MUTANT=1`)

The epochs floor is set to (number of reconfigure steps in the schedule) + 1. Each request commits at most one
epoch, in A (`commits` gets one record per decided request) and in R (one `dc` entry per decided request), so no
run reaches it. The verdict must be NO-SUPPORT, after a complete search. In arm A, the complete search of the mutant
visits exactly the distinct-state count of the author's own checking run (P1: 20,852; H13: 101,502, from
`model/.work/<id>/MC.out`). The probe therefore explores the space the author checked: not a smaller one, and not
a different one.

def reach_rows():
    """derives: experiments/X3/reach.md, experiments/X3/holdout/reach.md -- the registered floors, as committed"""
    rows = {}
    for f in (TUPAY / 'experiments/X3/reach.md', HOLDOUT / 'reach.md'):
        for ln in f.read_text().splitlines():
            m = re.match(r'^\| ([\w-]+) \| (\d+)/(\d+) \|(.*)\|\s*$', ln)
            if not m:
                continue
            rest = [c.strip() for c in m.group(4).split('|')]
            vals = [int(m.group(2)), int(m.group(3))] + [int(x) for x in rest]
            if len(vals) != len(COLS):
                die(f'reach row {m.group(1)} has {len(vals)} columns')
            rows[m.group(1)] = dict(zip(COLS, vals))
    return rows


def sha(p):
    return hashlib.sha256(Path(p).read_bytes()).hexdigest()


def main(argv):
    if len(argv) != 5 or argv[1] not in ('A', 'R') or argv[4] not in ('0', '1'):
        die(__doc__)

        if want.get(f'{sid}.yaml') != sha(sched):

            die(f'no schedule {sched}')

    src, tlc = out / 'src', out / 'tlc'
    src.mkdir(parents=True)
    tlc.mkdir(parents=True)
    for f in ('compile.py', 'Lease.tla'):
        shutil.copy(model / f, src / f)
    shutil.copy(sched, src / f'{sid}.yaml')
    doc = yaml.safe_load((src / f'{sid}.yaml').read_text())
    nreconf = sum(1 for s in doc['steps'] if 'reconfigure' in (s.get('do') or {}))
    if mutant:
        floors['epochs'] = nreconf + 1

    spec = importlib.util.spec_from_file_location('side_compile', src / 'compile.py')

    # derives: scripts/steward/x3-runs.sh (run.sh <name>, no flags) -- the side's own compiler at its own defaults
    if side == 'A':
        # model/run.py check(): compiler.compile_schedule(path, dirp, Lease.tla) -> MC.tla, MC.cfg

                      if not l.startswith('INVARIANT') and not l.startswith('PROPERTY'))
        bounds = f"MaxTerm {meta['max_term']}, MaxDups {meta['max_dups']}"
        nodes, cfgm, clients = (len(meta['processes']['lease']), len(meta['processes']['config']),
                                len(meta['processes']['clients']))
        author_cfg, tlc_flags = 'MC.cfg', '-deadlock -cleanup -checkpoint 5'
        cap = meta['max_term']
    else:
        # model-regen/run.py run_one(name): C.compile_schedule(sched, None, None); C.write_outputs(..., 'Lease')
        const, meta = C.compile_schedule(doc, None, None)
        C.write_outputs(const, meta, str(tlc), 'Lease')
        shutil.copy(src / 'Lease.tla', tlc / 'Lease.tla')
        base_cfg = (tlc / 'safety.cfg').read_text()
        # the author's safety run, without its invariants and action properties; deadlock checking off (a terminal
        # state is not a reach question, and TLC would stop at the first one)
        cfg = base_cfg.split('INVARIANTS')[0].replace('CHECK_DEADLOCK TRUE', 'CHECK_DEADLOCK FALSE')
        bounds = (f"MaxTerm {meta['max_term']} (TermCap MaxTerm + {len(meta['lease'])} after the last fault), "
                  f"Spur0 {meta['spur']}")
        nodes, cfgm, clients = len(meta['lease']), len(meta['config']), len(meta['clients'])
        author_cfg, tlc_flags = 'safety.cfg', '-nowarning'
        cap = meta['max_term'] + len(meta['lease'])
    (tlc / 'Probe.cfg').write_text(f'\\* derives: experiments/X3-prereg.md Departure 3 (support audit); '
                                   f'the author\'s {author_cfg} with NoFloor as the only invariant\n'
                                   + cfg + 'INVARIANT NoFloor\n')

    # structural floors, from the compiled constants
    structural = {'lease': nodes, 'config': cfgm, 'clients': clients}
    smiss = [f'{c} needs {floors[c]}, compiled {structural[c]}' for c in structural if structural[c] < floors[c]]

    defs, lines, used, vac = [], [], [], []
    for c in COLS:
        kind, e = EXPR[side][c]
        k = floors[c]
        expr = e.format(k=k)
        lines.append(f'{c}\tfloor {k}\t{kind}\t{expr if k > 0 else "(floor 0: not conjoined)"}')
        if k <= 0:
            continue
        defs.append(f'AuditF_{c} == {expr}')
        used.append(c)
        if kind == 'vacuous':
            vac.append(c)
    mod = ['---- MODULE Probe ----',
           f'\\* derives: experiments/X3-prereg.md Departure 3 (support audit), experiments/X3/reach.md row {sid}'
           + (' (MUTANT: epochs floor raised)' if mutant else ''),
           'EXTENDS MC, Integers, FiniteSets, Sequences, TLC',
           '\\* derives: experiments/X3-prereg.md Departure 3 -- sum of a function over a finite set (incarnations)',
           'RECURSIVE AuditSum(_, _)',
           'AuditSum(auditF, auditS) == IF auditS = {} THEN 0 ELSE LET auditX == CHOOSE auditY \\in auditS : TRUE '
           'IN auditF[auditX] + AuditSum(auditF, auditS \\ {auditX})',
           '\\* derives: experiments/X3-prereg.md Departure 3 -- schedule steps of kind k already taken (1..pc-1)',
           f'AuditStepsDone(auditK) == Cardinality({{ai \\in 1..(pc - 1) : {STEPKIND[side]} = auditK}})',
           '\\* derives: experiments/X3/reach.md -- one conjunct per nonzero floor of the row (MAPPING.md)']
    mod += defs
    mod.append('Floor == ' + (' /\\ '.join(f'AuditF_{c}' for c in used) if used else 'TRUE'))
    mod.append('NoFloor == ~Floor')
    for c in used:   # for SPLIT=1 diagnosis: each floor alone
        mod.append(f'AuditNo_{c} == ~AuditF_{c}')
    mod.append('====')
    (tlc / 'Probe.tla').write_text('\n'.join(mod) + '\n')
    (out / 'floors.txt').write_text(
        f'side {side} schedule {sid} mutant {int(mutant)}\nbounds (the side\'s own defaults): {bounds}\n'
        + '\n'.join(notes) + '\n' + '\n'.join(lines) + '\n')
    plan = {'side': side, 'schedule': sid, 'mutant': mutant, 'floors': floors, 'used': used, 'vacuous': vac,
            'structural_miss': smiss, 'bounds': bounds, 'term_cap': cap, 'tlc_flags': tlc_flags,
            'notes': notes}
    json.dump(plan, open(out / 'plan.json', 'w'), indent=1)
    print(json.dumps({'used': used, 'vacuous': vac, 'structural_miss': smiss, 'flags': tlc_flags}))
    return 0

===== the audit driver (audit.sh) =====
#!/bin/bash
# X3 support audit: one model side, one schedule. Is a state meeting every floor of the schedule's registered reach
# row in the side's checked space, at the side's own bounds?
# usage: audit.sh <A|R> <schedule-id> <outdir>      env: MUTANT=1 (anti-theater: an unreachable epochs floor; must
#        give NO-SUPPORT), SPLIT=1 (after NO-SUPPORT, probe each floor alone, to say which), AUDIT_TIMEOUT seconds
#        (default 0 = none; a run stopped by it is ERROR), TLA2TOOLS, AUDIT_CLONE_A / AUDIT_CLONE_R (clone roots)
# derives: experiments/X3-prereg.md Departure 3 (probe method: TLC at the author's stated bounds, an invariant negating
#          a state that meets every floor of the row; passes iff violated; "no support"; "vacuous by design") and
#          measure 1(a); experiments/X3/reach.md and holdout/reach.md (floors); scripts/steward/x3-runs.sh (how the
#          sides were run: the side's own compiler and cfg, no flags); docs/steward-practice.md (memory cap)
# Verdict (last line of <outdir>/verdict.txt, also printed):
#   SUPPORT      TLC reports NoFloor violated (trace length = states in TLC's trace)
#   NO-SUPPORT   TLC completed the search and NoFloor held (or a structural floor exceeds the compiled constants)
#   VACUOUS      the row needs a quantity the side does not model; the modelled floors are probed and reported beside it
#   ERROR        anything else (compile rejection, TLC error, time limit)
# Writes only into <outdir>; the clone is read (and checked unwritten afterwards with find -newer).
set -uo pipefail
SIDE=${1:?side A or R}; SID=${2:?schedule id}; O=$(realpath -m "${3:?outdir}")
HERE=$(dirname "$(realpath "$0")")
[ -e "$O" ] && { echo "exists: $O"; exit 1; }
mkdir -p "$O"; : > "$O/.start-marker"
JAR=${TLA2TOOLS:-$HOME/projects/tlaplus/tla2tools.jar}
case $SIDE in
  A) CLONE=${AUDIT_CLONE_A:-$HOME/projects/tupay-x3-score/armA-model} ;;
  R) CLONE=${AUDIT_CLONE_R:-$HOME/projects/tupay-x3-score/armR-model} ;;
  *) echo "side must be A or R"; exit 1 ;;
esac
{ echo "side=$SIDE schedule=$SID mutant=${MUTANT:-0}"; echo "clone=$CLONE commit=$(git -C "$CLONE" rev-parse HEAD)"
  echo "TLA2TOOLS=$JAR $(sha256sum "$JAR" | cut -c1-16)"; java -version 2>&1 | head -1
  echo "audit.sh $(sha256sum "$0" | cut -c1-16) probe.py $(sha256sum "$HERE/probe.py" | cut -c1-16)"; } > "$O/env.txt"

verdict() { echo "VERDICT side=$SIDE schedule=$SID mutant=${MUTANT:-0} $*" | tee -a "$O/verdict.txt"; }

if ! PYTHONDONTWRITEBYTECODE=1 uv run -q --no-project --with pyyaml==6.0.3 python -B "$HERE/probe.py" \
     "$SIDE" "$SID" "$O" "${MUTANT:-0}" > "$O/probe.json" 2> "$O/probe.err"; then
  verdict "ERROR compile: $(tail -1 "$O/probe.err")"; exit 0
fi
FLAGS=$(python3 -c 'import json,sys; print(json.load(open(sys.argv[1]))["flags"])' "$O/probe.json")
SMISS=$(python3 -c 'import json,sys; print("; ".join(json.load(open(sys.argv[1]))["structural_miss"]))' "$O/probe.json")
VAC=$(python3 -c 'import json,sys; print(", ".join(json.load(open(sys.argv[1]))["vacuous"]))' "$O/probe.json")

# one TLC run on Probe.tla with invariant $1; prints "<result> <trace-length> <distinct> <seconds>"
run_tlc() {
  local inv=$1 cfg=Probe.cfg log="$O/tlc-$1.out" t0 rc=0
  if [ "$inv" != NoFloor ]; then cfg=Probe-$inv.cfg; sed "s/^INVARIANT NoFloor$/INVARIANT $inv/" "$O/tlc/Probe.cfg" > "$O/tlc/$cfg"; fi
  mkdir -p "$O/jtmp"; t0=$(date +%s)
  ( cd "$O/tlc" && timeout "${AUDIT_TIMEOUT:-0}" systemd-run --user --scope -q -p MemoryMax=12G -p MemorySwapMax=0 \
      java -Xmx8g -XX:+UseParallelGC -Djava.io.tmpdir="$O/jtmp" -cp "$JAR" tlc2.TLC $FLAGS -workers 8 \
      -metadir "$O/states-$inv" -config "$cfg" Probe ) > "$log" 2>&1 || rc=$?
  local secs=$(( $(date +%s) - t0 )) res
  local distinct; distinct=$(grep -oE '[0-9,]+ distinct states found' "$log" | tail -1 | cut -d' ' -f1)
  if grep -q "Invariant $inv is violated" "$log"; then res=VIOLATED
  elif grep -q "Model checking completed. No error has been found." "$log"; then res=HOLDS
  elif [ $rc -eq 124 ]; then res=TIMEOUT
  else res=ERROR; fi
  echo "$res $(grep -cE '^State [0-9]+:' "$log") ${distinct:-?} $secs"
}

if [ -n "$SMISS" ]; then
  verdict "NO-SUPPORT structural: $SMISS"
else
  read -r RES LEN DIST SECS < <(run_tlc NoFloor)
  case $RES in
    VIOLATED) V="SUPPORT trace=$LEN states=$DIST seconds=$SECS" ;;
    HOLDS)    V="NO-SUPPORT search complete, distinct=$DIST seconds=$SECS" ;;
    TIMEOUT)  V="ERROR time limit ${AUDIT_TIMEOUT}s, distinct=$DIST" ;;
    *)        V="ERROR TLC: $(grep -m1 -E '^Error|Exception' "$O/tlc-NoFloor.out" | cut -c1-200) seconds=$SECS" ;;
  esac
  if [ "$RES" = HOLDS ] && [ "${SPLIT:-0}" = 1 ]; then
    for c in $(python3 -c 'import json,sys; print(" ".join(json.load(open(sys.argv[1]))["used"]))' "$O/probe.json"); do
      read -r r l d s < <(run_tlc "AuditNo_$c"); echo "split $c: $r trace=$l distinct=$d seconds=$s" >> "$O/split.txt"
    done
    V="$V; split: $(tr '\n' ';' < "$O/split.txt")"
  fi
  if [ -n "$VAC" ]; then verdict "VACUOUS not modelled: $VAC; modelled floors (vacuous ones by step position): $V"
  else verdict "$V"; fi
fi
rm -rf "$O"/states-* "$O/jtmp"
W=$(find "$CLONE" -newer "$O/.start-marker" -print 2>/dev/null | head -5)
[ -n "$W" ] && echo "WARNING: files in the clone changed during the run: $W" | tee -a "$O/verdict.txt"
exit 0

IsStart(T) == T.event = "start"
\* derives: F1.1, F1.2, F1.3; format v2.1 T1 -- every filter field of trigger T equals record r's
FOK(T, r) == \A f \in (DOMAIN T) \ {"event"} : f \in DOMAIN r /\ r[f] = T[f]
\* derives: F1.1, F1.2, F1.3, F3.1; format v2.1 T1, v5 -- an event the model emits matches a trigger.
\* X3: a decided commit (`Commit`) and a learned one (`Learn`) are the schema's ConfigCommitted with
\* decided true and false; a refusal is ReconfigRefused; a grant or commit step carries the Agree
\* and Agreed records of the agreements it counted.
Match1(T, e) ==
    \/ /\ T.event \notin {"ConfigCommitted", "ReconfigRefused", "Agree", "Agreed"}
       /\ e.event = T.event /\ FOK(T, e)
    \/ /\ T.event = "ConfigCommitted" /\ e.event = "Commit"
       /\ FOK(T, [epoch |-> e.rec.ep, members |-> e.rec.mem, request_id |-> e.rec.rid,
                  decided |-> TRUE, node |-> e.node])
    \/ /\ T.event = "ConfigCommitted" /\ e.event = "Learn"
       /\ \E i \in 1..Len(e.recs) :
            FOK(T, [epoch |-> e.recs[i].ep, members |-> e.recs[i].mem, request_id |-> e.recs[i].rid,
                    decided |-> FALSE, node |-> e.node])
    \/ /\ T.event = "ReconfigRefused" /\ e.event = "Refused" /\ FOK(T, e)
    \/ /\ T.event \in {"Agree", "Agreed"} /\ e.event \in {"Grant", "Commit"}
\* derives: F1.1, F1.2, F1.3; format v2.1 T1 -- some event of the sequence evs matches trigger T. Only
\* events emitted while the trigger is armed are ever offered to it (Emit and ScheduleStep), which is
\* T1's "matches only events emitted after it was armed". `quiescent` (E1) is a state predicate.

                   /\ \E i \in 1..Len(evs) : Match1(T, evs[i])

\* derives: C1.1, C1.2, C1.3, F1.1, F1.2, F1.3
\* Protocol step emitting the events evs: record them, and advance the current trigger.
\* Must be the last conjunct of an action (uses grants', up').

             /\ fired' = (fired \/ Matches(Trig(pc), evs))
             /\ trigG' = IF ~fired /\ Matches(Trig(pc), evs) THEN LastGrant' ELSE trigG
             /\ trigNG' = IF ~fired /\ Matches(Trig(pc), evs)
                          THEN {n \in Nodes : up'[n]} \ {LastGrant'.node} ELSE trigNG
             /\ trigNM' = IF ~fired /\ Matches(Trig(pc), evs)
                          THEN Nodes \ (IF commits' = <<>> THEN Init0Rec
                                        ELSE commits'[CHOOSE i \in 1..Len(commits') :
                                               \A j \in 1..Len(commits') : commits'[j].rec.ep <= commits'[i].rec.ep].rec).mem
                          ELSE trigNM
             /\ UNCHANGED <<pc, ngDown>>

\* round-1 to X2 model recorded the internal step's name, which only multiplied states).
Internal(what, p) == Emit(<<>>)

\* Grantor (abstract Raft with joint consensus): leader per term, eligible-majority election
\* over the newest configuration the voters know, majority-counted grants and commits
\* ===========================================================================

\* derives: C1.1, C1.4, F1.2, F2.1, F2.2 -- node x hears a current leader: an up leader m
\* whose term is at least x's promise, over the link m->x (hearing is directional: F2.2).
\* A leader hears itself.
HearsLeader(x) == \E m \in Nodes : up[m] /\ Link(m, x) /\ leader[m] /\ term[m] >= promised[x]

\* ---------------------------------------------------------------------------
\* Learning a commit at a receiver (derives: C3.4, C3.8, F3.1). When node x's configuration
\* history becomes H and reaches the epoch its pending request targets, the request is no
\* longer pending: it is x's commit if H's configuration of that epoch names it, else it is
\* superseded (contract v3 C3.4(b)). Either way x owes the operator the outcome.
\* derives: C3.4, F3.1
Res(x, H) == pend[x] # NoPend /\ Len(H) - 1 >= pend[x].tgt
\* derives: C3.4, C3.8, F3.1
ResCommitted(x, H) == H[pend[x].tgt + 1].rid = pend[x].rid
\* derives: C3.4, F3.1
NewPend(x, H) == IF Res(x, H) THEN NoPend ELSE pend[x]
\* derives: C3.4, C3.8, F3.1
NewOwed(x, H) == IF Res(x, H)
                 THEN owed[x] \cup {[op |-> pend[x].op, rid |-> pend[x].rid,
                                     outcome |-> IF ResCommitted(x, H) THEN "committed" ELSE "refused",
                                     ep |-> pend[x].tgt, x |-> x]}
                 ELSE owed[x]
\* derives: C3.4, C3.5, F3.1 -- the refusal decision, with its recorded inputs
NewRefusals(x, H) == IF Res(x, H) /\ ~ResCommitted(x, H)
                     THEN Append(refusals, [x |-> x, rid |-> pend[x].rid, mem |-> pend[x].mem,
                                            reason |-> "superseded", pin |-> "none", cin |-> pend[x].tgt])
                     ELSE refusals
\* derives: C3.4, F3.1 -- the ReconfigRefused event, if any
ResEv(x, H) == IF Res(x, H) /\ ~ResCommitted(x, H)
               THEN <<[event |-> "Refused", node |-> x, request_id |-> pend[x].rid, reason |-> "superseded",
                       epoch |-> pend[x].tgt, members |-> pend[x].mem, pending |-> "none"]>>
               ELSE <<>>
\* derives: C3.1, F3.1 -- the ConfigCommitted (decided: false) events of the epochs x learns
LearnEv(x, H) == IF Len(H) > Len(cfg[x])
                 THEN <<[event |-> "Learn", node |-> x, recs |-> SubSeq(H, Len(cfg[x]) + 1, Len(H))]>>
                 ELSE <<>>

\* derives: C1.1, C1.4, F1.1, F1.2, F2.1, F2.2, C3.1, C3.7, F3.1, F3.2, F3.3
\* A node that hears no leader of a term at least its own promise starts an election;
\* a quorum Q (up, connected to n both ways: a vote is a round trip) promises a fresh
\* term; the new leader learns the highest token any member of Q agreed to.
\* X2: each voter must itself hear no current leader (voter stickiness, a pre-vote check).
\* derives: C1.4, F2.1 -- under F2.1 a follower cut off from a grantor that still has a
\* majority can reach a node that still hears it; the voter refuses, so the cut-off
\* follower cannot disrupt the grantor (P19, P25). Under v1 bipartitions every node a
\* candidate could reach was on its side and heard no leader either.
\* X3 (derives: C3.1, C3.7, F3.1, F3.3): the leader adopts the newest configuration history its
\* voters know (Adopt), and Q must be an eligible majority of that configuration, every voter an
\* eligible member of it (Raft: a server uses the latest configuration in its log; an amnesic
\* incarnation does not vote until re-admitted, Paxos Made Live 5.1). It records what it learned.
\* derives: F3.2 -- a node whose timer fired early (forward clock step) may stand or vote although it
\* hears a leader; standing or voting resets its timer.
Elect(n) ==
    /\ UNCHANGED rvars  \* derives: C2.1, C2.2 -- reads untouched
    /\ up[n] /\ ~leader[n]
    /\ ~HearsLeader(n) \/ early[n]
    /\ \E Q \in SUBSET {q \in Nodes : up[q] /\ Conn(n, q)} :
        LET H == Adopt(Q)
            X == H[Len(H)]
            R == RdmOf(H) IN
        /\ n \in Q
        /\ \A q \in Q : EligIn(q, X.mem, R)         \* derives: C3.7, F3.3
        /\ MajOf(Q, X.mem)
        /\ \A q \in Q : ~HearsLeader(q) \/ early[q]   \* derives: C1.4, F2.1, F3.2 -- voter stickiness
        /\ LET t == 1 + Max({promised[q] : q \in Q}) IN
           /\ t <= MaxTerm
           /\ promised' = [q \in Nodes |-> IF q \in Q THEN t ELSE promised[q]]
           /\ leader' = [q \in Nodes |-> IF q = n THEN TRUE
                                         ELSE IF q \in Q THEN FALSE ELSE leader[q]]
           /\ term' = [term EXCEPT ![n] = t]
           /\ ltok' = [ltok EXCEPT ![n] = Max({maxTok[q] : q \in Q})]
        /\ early' = [q \in Nodes |-> IF q \in Q THEN FALSE ELSE early[q]]
        /\ cfg' = [cfg EXCEPT ![n] = H]
        /\ jprop' = [jprop EXCEPT ![n] = IF @.ep <= Len(H) - 1 THEN NoConf ELSE @]
        /\ pend' = [pend EXCEPT ![n] = NewPend(n, H)]
        /\ owed' = [owed EXCEPT ![n] = NewOwed(n, H)]
        /\ refusals' = NewRefusals(n, H)
        /\ UNCHANGED <<up, paused, down, maxTok, reqs, pending, tok, myToks, awaiting,
                       grantMsgs, writeMsgs, ackMsgs, dups, highest, stval, toAck,
                       grants, rq, issued, decisions, told>>
        /\ UNCHANGED <<inc, rcMsgs, opMsgs, commits, opTold, off, agreeLog>>
        /\ Emit(LearnEv(n, H) \o ResEv(n, H))

    /\ \E q \in Nodes : up[q] /\ Link(q, n) /\ promised[q] > term[n]
    /\ leader' = [leader EXCEPT ![n] = FALSE]
    /\ promised' = [promised EXCEPT ![n] =
                      Max({promised[q] : q \in {x \in Nodes : up[x] /\ Link(x, n)}})]
    /\ UNCHANGED <<up, paused, down, maxTok, term, ltok, reqs, pending, tok, myToks,
                   awaiting, grantMsgs, writeMsgs, ackMsgs, dups, highest, stval,
                   toAck, grants, rq, issued, decisions, told>>

\* derives: C3.8, F3.1 -- the nodes leader n replicates to: its configuration's members and the members a
\* request for its next epoch names
JoinScope(n) == Cur(n).mem \cup UNION {pend[x].mem : x \in {y \in Nodes : pend[y].tgt = CurEp(n) + 1}}

\* derives: C1.4, F1.1, F1.2, F2.2 -- the P10 fix (judge's verdict, locus: model).
\* X2: it needs only the link n->q (the leader's message reaches q).
\* A leader brings a reachable, up, lagging node into its term: the node raises its
\* promise to the leader's term (and, if it was a stale leader, stops leading).
\* Without this, a leader elected by a non-maximal majority whose other member then
\* crashes can never assemble a grant majority, while no election or step-down is
\* enabled either: C1.4 fails with a majority, storage and the requester all up and
\* connected. Raising a promise is always safe here: promises only grow, and a grant
\* still needs a majority promised to exactly the leader's term.
\* X3 (derives: C3.8, F3.1, F3.3): the leader replicates to the members of its current configuration
\* and, once a request for the next epoch is pending, to the members it requests (Raft thesis
\* 4.2.1: new servers are caught up as non-voting members); an amnesic member is joined like any
\* other, and its agreements count only if eligible One heartbeat reaches every such node whose
\* link from the leader is up, in one step (README X3 "Abstractions"; before X3, one node per step).
Join(n) ==
    /\ UNCHANGED rvars  \* derives: C2.1, C2.2 -- reads untouched
    /\ UNCHANGED kvars  \* derives: C3.x -- configuration untouched
    /\ UNCHANGED xvars
    /\ up[n] /\ leader[n]
    /\ LET J == {q \in JoinScope(n) : up[q] /\ q # n /\ Link(n, q) /\ promised[q] < term[n]} IN
       /\ J # {}
       /\ promised' = [q \in Nodes |-> IF q \in J THEN term[n] ELSE promised[q]]
       /\ leader' = [q \in Nodes |-> IF q \in J THEN FALSE ELSE leader[q]]
    /\ UNCHANGED <<up, paused, down, maxTok, term, ltok, reqs, pending, tok, myToks,
                   awaiting, grantMsgs, writeMsgs, ackMsgs, dups, highest, stval,
                   toAck, grants, rq, issued, decisions, told>>
    /\ Internal("Join", n)

\* derives: C1.4, F2.2, F2.1, F1.2 -- the quorum check (new in X2). A leader that is not
\* connected (both ways) to a majority of up lease nodes, itself included, stops leading.
\* Under F2.2 the followers may still hear a grantor that cannot hear them; their
\* failure detector then never fires and, without this, nobody would ever elect (P26).
\* Under v1 it only lets a grantor isolated in a minority stop sooner.
\* X3 (derives: C1.4, C3.7, F3.1, F3.2, F3.3): the majority is of eligible members of the leader's
\* current configuration; a leader that is no longer an eligible member of it steps down (Raft
\* thesis 4.2.2, a removed leader steps down once the change is committed); and a forward clock
\* step may fire the quorum timer early (a spurious step-down).
CheckQuorum(n) ==
    /\ UNCHANGED rvars  \* derives: C2.1, C2.2 -- reads untouched
    /\ UNCHANGED kvars
    /\ UNCHANGED <<off, agreeLog>>
    /\ up[n] /\ leader[n]
    /\ \/ ~Elig(n, n)
       \/ ~MajOf({q \in Nodes : up[q] /\ Conn(n, q) /\ Elig(q, n)}, Cur(n).mem)
       \/ early[n]
    /\ leader' = [leader EXCEPT ![n] = FALSE]
    /\ early' = [early EXCEPT ![n] = FALSE]
    /\ UNCHANGED <<up, paused, down, promised, maxTok, term, ltok, reqs, pending, tok, myToks,
                   awaiting, grantMsgs, writeMsgs, ackMsgs, dups, highest, stval,
                   toAck, grants, rq, issued, decisions, told>>
    /\ Internal("CheckQuorum", n)

\* derives: C1.4, F2.1, F2.2; format v4 L3 -- routing fix: a client's (retried) request reaches
\* lease node n directly, or relayed by one up lease node f (c->f and f->n up). Under L3 the
\* requester need not reach the grantor; a grantor that keeps its place (CheckQuorum) is
\* connected to a majority, which shares a member with the premise's majority, and that
\* member is connected to both: one hop is enough.
ReqRoute(c, n) == Link(c, n) \/ \E f \in Nodes : up[f] /\ Link(c, f) /\ Link(f, n)
\* derives: C1.4, F2.1, F2.2; format v4 L3 -- a grant reply from n reaches c directly or through
\* one up lease node; its fate is fixed when n sends it (the relay forwards at once)
RepRoute(n, c) == Link(n, c) \/ \E f \in Nodes : up[f] /\ Link(n, f) /\ Link(f, c)

\* derives: C1.1, C1.4, F1.1, F1.2, F2.1, F2.2, C3.5, C3.7, F3.1, F3.3; format v4 L3; observe v4, v5
\* The leader issues a grant to a requester whose request reaches it (ReqRoute), once a
\* majority still promised to its term, and connected to it (an agreement is a round
\* trip), durably agrees to the token. The Grant is recorded whether or not the reply can
\* be delivered (F2.2: a grantor may hear a requester it cannot answer, H8); the reply is in
\* flight only if RepRoute holds when it is sent. A leader answers each request at most once
\* per term; a lost reply is retransmitted by Resend (no new Grant record).
\* X3 (C3.7): the grant is issued under the leader's current configuration and counted by eligible
\* agreements from a majority of it; the leader must itself be an eligible member. The record
\* carries its configuration epoch and its inputs (C3.5): the counted agreements, the members and
\* epoch counted against, the term, and the last token the leader knew (`last_token`); the
\* token is last_token + 1. No clock is read.
Grant(n, c) ==
    /\ UNCHANGED rvars  \* derives: C2.1, C2.2 -- reads untouched
    /\ UNCHANGED kvars
    /\ UNCHANGED <<off, early>>
    /\ up[n] /\ leader[n]
    /\ Elig(n, n)                                       \* derives: C3.7, F3.1, F3.3
    /\ c \in reqs
    /\ ReqRoute(c, n)
    /\ ~\E m \in grantMsgs : m.c = c
    /\ ~\E x \in issued : x.n = n /\ x.g = term[n] /\ x.c = c /\ x.r = rq[c]
    /\ \E Q \in SUBSET {q \in Nodes : up[q] /\ Conn(n, q) /\ promised[q] = term[n] /\ Elig(q, n)} :
        /\ n \in Q
        /\ MajOf(Q, Cur(n).mem)                         \* derives: C3.7
        /\ LET k == ltok[n] + 1
               ag == {<<q, inc[q]>> : q \in Q} IN
           /\ maxTok' = [q \in Nodes |-> IF q \in Q THEN Max({maxTok[q], k}) ELSE maxTok[q]]
           /\ ltok' = [ltok EXCEPT ![n] = k]
           /\ grantMsgs' = IF RepRoute(n, c)
                           THEN grantMsgs \cup {[n |-> n, c |-> c, t |-> k, g |-> term[n]]}
                           ELSE grantMsgs
           /\ issued' = issued \cup {[n |-> n, c |-> c, r |-> rq[c], t |-> k, g |-> term[n]]}
           /\ grants' = Append(grants, [token |-> k, term |-> term[n], node |-> n, client |-> c,
                                        ninc |-> inc[n], ep |-> CurEp(n), cep |-> CurEp(n),
                                        mem |-> Cur(n).mem, ag |-> ag, lt |-> ltok[n]])
           /\ agreeLog' = [q \in Nodes |-> IF q \in Q THEN Append(agreeLog[q], [i |-> inc[q], t |-> k])
                                           ELSE agreeLog[q]]   \* derives: C1.1
           /\ UNCHANGED rq
           /\ UNCHANGED <<up, paused, down, promised, leader, term, reqs, pending, tok,
                          myToks, awaiting, writeMsgs, ackMsgs, dups, highest, stval,
                          toAck, decisions, told>>
           /\ Emit(<<[event |-> "Grant", client |-> c, key |-> Key, token |-> k,
                      lifetime |-> Lifetime, grantor_term |-> term[n], node |-> n, ninc |-> inc[n],
                      config_epoch |-> CurEp(n), members |-> Cur(n).mem, last_token |-> ltok[n],
                      agreed |-> ag]>>)

\* derives: C1.4, F2.1, F2.2; observe v4 "Grants and retransmission" -- the leader retransmits
\* the grant it already issued for c's current request, while the request still reaches it
\* and a reply route exists. Not a new grant: no Grant record, same token.
Resend(n, c) ==
    /\ UNCHANGED rvars  \* derives: C2.1, C2.2 -- reads untouched
    /\ UNCHANGED kvars
    /\ UNCHANGED xvars
    /\ up[n] /\ leader[n]
    /\ c \in reqs
    /\ ReqRoute(c, n) /\ RepRoute(n, c)
    /\ ~\E m \in grantMsgs : m.c = c
    /\ \E x \in issued :
        /\ x.n = n /\ x.g = term[n] /\ x.c = c /\ x.r = rq[c]
        /\ grantMsgs' = grantMsgs \cup {[n |-> n, c |-> c, t |-> x.t, g |-> x.g]}
    /\ UNCHANGED <<up, paused, down, promised, maxTok, leader, term, ltok, reqs, pending, tok,
                   myToks, awaiting, writeMsgs, ackMsgs, dups, highest, stval, toAck,
                   grants, rq, issued, decisions, told>>
    /\ Internal("Resend", n)

\* derives: C1.4, F1.3 -- a (running, unpaused) client receives a grant reply
RecvGrant(m) ==
    /\ UNCHANGED rvars  \* derives: C2.1, C2.2 -- reads untouched
    /\ UNCHANGED kvars
    /\ UNCHANGED xvars
    /\ m \in grantMsgs
    /\ up[m.c] /\ ~paused[m.c]
    /\ grantMsgs' = grantMsgs \ {m}
    /\ IF pending[m.c]
       THEN /\ tok' = [tok EXCEPT ![m.c] = [t |-> m.t, g |-> m.g]]
            /\ myToks' = [myToks EXCEPT ![m.c] = @ \cup {[t |-> m.t, g |-> m.g]}]
            /\ pending' = [pending EXCEPT ![m.c] = FALSE]
            /\ reqs' = reqs \ {m.c}
       ELSE UNCHANGED <<tok, myToks, pending, reqs>>
    /\ UNCHANGED <<up, paused, down, promised, maxTok, leader, term, ltok, awaiting,
                   writeMsgs, ackMsgs, dups, highest, stval, toAck, grants, rq, issued, decisions, told>>
    /\ Internal("RecvGrant", m.c)

\* ===========================================================================
\* Configuration change (contract v3, failure model F3.1; Raft joint consensus, README X3)
\* ===========================================================================

\* derives: C3.4, F2.1, F2.2, F3.1; format v4 L3 -- a receiver passes its pending request to the leader
\* directly or through one up lease node (as a client's request, FR.1)
FwdRoute(x, l) == Link(x, l) \/ \E f \in Nodes : up[f] /\ Link(x, f) /\ Link(f, l)

\* derives: C3.8, F3.1 -- nodes in M that can agree to leader l's configuration proposal: up, connected
\* to l, promised to its term, and caught up to l's configuration history (Raft thesis 4.2.1: a
\* new server is caught up before it counts)
Agreeable(l, M) == {q \in M \cap Nodes : up[q] /\ Conn(l, q) /\ promised[q] = term[l]
                                         /\ Len(cfg[q]) = Len(cfg[l])}

\* derives: C3.1, C3.5, C3.8, F3.1, F3.3; contract v3 "Re-admission"
\* Leader l decides the request pending at receiver x as the next epoch: eligible agreements
\* from a majority of its current configuration (Qo) and of the requested set (Qn), one
\* agreement for a node in both. Amnesic incarnations in the requested set that agree (Rr) are
\* recorded, not counted, and re-admitted. Everyone who agreed keeps the proposal and the
\* leader's token count (the joint entry and the log before it). The decision and the
\* agreements are one step (README X3). If x = l, its request is resolved at once.
Commit(l, x) ==
    LET r == pend[x]
        e == CurEp(l)
        Old == Cur(l)
        R == RdmOf(cfg[l]) IN
    /\ UNCHANGED rvars
    /\ UNCHANGED <<inc, rcMsgs, opMsgs, opTold, xvars>>
    /\ up[l] /\ leader[l] /\ Elig(l, l)
    /\ up[x] /\ r # NoPend
    /\ x = l \/ FwdRoute(x, l)
    /\ r.tgt = e + 1
    /\ \E Qo \in SUBSET {q \in Agreeable(l, Old.mem) : EligIn(q, Old.mem, R)},
          Qn \in SUBSET {q \in Agreeable(l, r.mem) : EligIn(q, r.mem, R)},
          Rr \in SUBSET {q \in Agreeable(l, r.mem) : inc[q] > 0 /\ <<q, inc[q]>> \notin R} :
        /\ l \in Qo
        /\ Qo \cap r.mem = Qn \cap Old.mem
        /\ MajOf(Qo, Old.mem) /\ MajOf(Qn, r.mem)
        /\ LET A == Qo \cup Qn \cup Rr
               X == [ep |-> e + 1, mem |-> r.mem, rid |-> r.rid,
                     rdm |-> {<<q, inc[q]>> : q \in {p \in A : inc[p] > 0 /\ p \in r.mem}}, by |-> l]
               H == Append(cfg[l], X)
               ago == {<<q, inc[q]>> : q \in Qo}
               agn == {<<q, inc[q]>> : q \in Qn}
               agr == {<<q, inc[q]>> : q \in Rr} IN
           /\ cfg' = [cfg EXCEPT ![l] = H]
           /\ jprop' = [q \in Nodes |-> IF q \in A \ {l} THEN X ELSE jprop[q]]
           /\ maxTok' = [q \in Nodes |-> IF q \in A THEN Max({maxTok[q], ltok[l]}) ELSE maxTok[q]]
           /\ commits' = Append(commits, [rec |-> X, ago |-> ago, agn |-> agn, agr |-> agr,
                                          old |-> Old.mem, oep |-> e, req |-> r.mem, node |-> l,
                                          ninc |-> inc[l]])
           /\ pend' = [pend EXCEPT ![l] = NewPend(l, H)]
           /\ owed' = [owed EXCEPT ![l] = NewOwed(l, H)]
           /\ refusals' = NewRefusals(l, H)
           \* derives: C3.7, F3.1 -- a leader the commit removes steps down with it (Raft thesis 4.2.2)
           /\ leader' = [leader EXCEPT ![l] = l \in r.mem]
           /\ UNCHANGED <<up, paused, down, promised, term, ltok, reqs, pending, tok,
                          myToks, awaiting, grantMsgs, writeMsgs, ackMsgs, dups, highest, stval,
                          toAck, grants, rq, issued, decisions, told>>
           /\ Emit(<<[event |-> "Commit", node |-> l, ninc |-> inc[l], rec |-> X, ago |-> ago,
                      agn |-> agn, agr |-> agr, old |-> Old.mem, oep |-> e, req |-> r.mem]>>
                   \o ResEv(l, H))

\* derives: C3.1, C3.4, F3.1, F3.3 -- node n learns the next committed configuration from m, which has
\* recorded it, over the link m->n (Raft: the leader's AppendEntries; here any node that has it
\* may teach it, which is safe because it is committed). An amnesic node learns its
\* configuration this way (contract v3: "learns its configuration from others").
LearnConfig(n, m) ==
    /\ UNCHANGED rvars
    /\ UNCHANGED <<inc, rcMsgs, opMsgs, commits, opTold, xvars>>
    /\ up[n] /\ up[m] /\ n # m /\ Link(m, n)
    /\ Len(cfg[m]) > Len(cfg[n])
    \* derives: C3.4, F3.1 -- m teaches a commit to the members of the configuration it commits, to a
    \* receiver holding a request (the answer to its forwarding), and to a node a pending request
    \* names (catch-up, Raft thesis 4.2.1); a node the commit removed need not learn of it
    /\ \/ n \in cfg[m][Len(cfg[n]) + 1].mem
       \/ pend[n] # NoPend
       \/ \E x \in Nodes : n \in pend[x].mem
    /\ LET H == Append(cfg[n], cfg[m][Len(cfg[n]) + 1]) IN
       /\ cfg' = [cfg EXCEPT ![n] = H]
       /\ jprop' = [jprop EXCEPT ![n] = IF @.ep <= Len(H) - 1 THEN NoConf ELSE @]
       /\ pend' = [pend EXCEPT ![n] = NewPend(n, H)]
       /\ owed' = [owed EXCEPT ![n] = NewOwed(n, H)]
       /\ refusals' = NewRefusals(n, H)
       /\ UNCHANGED <<up, paused, down, promised, maxTok, leader, term, ltok, reqs, pending, tok,
                      myToks, awaiting, grantMsgs, writeMsgs, ackMsgs, dups, highest, stval,
                      toAck, grants, rq, issued, decisions, told>>
       /\ Emit(LearnEv(n, H) \o ResEv(n, H))

\* derives: C3.4, C3.5, F3.1; contract v3 C3.4(a) -- receiver x records a request it receives and, in
\* this order, refuses it as `invalid` (empty, or naming a non-lease process) or `busy` (another
\* request pending here; the earlier one is kept), else holds it pending, targeting the epoch
\* after its current one.
RecvReconfig(m) ==
    LET x == m.to IN
    /\ UNCHANGED rvars
    /\ UNCHANGED <<inc, cfg, jprop, opMsgs, commits, opTold, xvars>>
    /\ m \in rcMsgs /\ up[x]
    /\ rcMsgs' = rcMsgs \ {m}
    /\ LET inval == m.mem = {} \/ ~(m.mem \subseteq Nodes)
           busy == ~inval /\ pend[x] # NoPend
           req == [event |-> "ReconfigRequest", node |-> x, operator |-> m.op, request_id |-> m.rid,
                   members |-> m.mem] IN
       IF inval \/ busy
       THEN /\ owed' = [owed EXCEPT ![x] = @ \cup {[op |-> m.op, rid |-> m.rid, outcome |-> "refused",
                                                    ep |-> -1, x |-> x]}]
            /\ refusals' = Append(refusals, [x |-> x, rid |-> m.rid, mem |-> m.mem,
                                             reason |-> IF inval THEN "invalid" ELSE "busy",
                                             pin |-> IF inval THEN "none" ELSE pend[x].rid, cin |-> -1])
            /\ UNCHANGED pend
            /\ UNCHANGED <<up, paused, down, promised, maxTok, leader, term, ltok, reqs, pending, tok,
                           myToks, awaiting, grantMsgs, writeMsgs, ackMsgs, dups, highest, stval,
                           toAck, grants, rq, issued, decisions, told>>
            /\ Emit(<<req, [event |-> "Refused", node |-> x, request_id |-> m.rid,
                            reason |-> IF inval THEN "invalid" ELSE "busy", epoch |-> -1,
                            members |-> m.mem, pending |-> IF inval THEN "none" ELSE pend[x].rid]>>)
       ELSE /\ pend' = [pend EXCEPT ![x] = [rid |-> m.rid, mem |-> m.mem, op |-> m.op, tgt |-> CurEp(x) + 1]]
            /\ UNCHANGED <<owed, refusals>>
            /\ UNCHANGED <<up, paused, down, promised, maxTok, leader, term, ltok, reqs, pending, tok,
                           myToks, awaiting, grantMsgs, writeMsgs, ackMsgs, dups, highest, stval,
                           toAck, grants, rq, issued, decisions, told>>
            /\ Emit(<<req>>)

\* derives: C3.4, C3.8, F2.1, F2.2 -- receiver x sends an outcome it owes the operator, and the operator
\* (which never crashes) is told it. The reply is sent only over an up link x->op (a send on a down
\* link is lost and x keeps owing it); its receipt is taken in the same step (README X3
\* "Abstractions": nothing in the contract depends on that delay).
ReplyOp(x, a) ==
    /\ UNCHANGED rvars
    /\ UNCHANGED <<inc, cfg, jprop, pend, rcMsgs, opMsgs, commits, refusals, xvars>>
    /\ up[x] /\ a \in owed[x]
    /\ Link(x, a.op)
    /\ owed' = [owed EXCEPT ![x] = @ \ {a}]
    /\ opTold' = opTold \cup {[op |-> a.op, rid |-> a.rid, outcome |-> a.outcome, ep |-> a.ep]}
    /\ UNCHANGED <<up, paused, down, promised, maxTok, leader, term, ltok, reqs, pending, tok,
                   myToks, awaiting, grantMsgs, writeMsgs, ackMsgs, dups, highest, stval,
                   toAck, grants, rq, issued, decisions, told>>
    /\ Emit(<<[event |-> "ReconfigAck", operator |-> a.op, request_id |-> a.rid, outcome |-> a.outcome,
               epoch |-> a.ep, node |-> x]>>)

\* derives: C1.2, C1.3, F1.1, C3.5 -- storage decides a write: accept iff token >= ledger (contract v3:
\* "storage decides deterministically"); on accept the token becomes the ledger and the value is
\* stored. The ack is queued (volatile) and sent by SendAck. dup = TRUE models a duplicated
\* delivery (the message stays in flight), bounded by MaxDups. X3: the decision records its
\* inputs (token, ledger, stored value, value); it reads no clock.
StorageDecide(m, dup) ==
    /\ UNCHANGED rvars  \* derives: C2.1, C2.2 -- reads untouched
    /\ UNCHANGED kvars
    /\ UNCHANGED xvars
    /\ up[Store]
    /\ m \in writeMsgs
    /\ dup => dups < MaxDups
    /\ LET acc == m.t >= highest
           out == IF acc THEN "accept" ELSE "reject" IN
       /\ highest' = IF acc THEN m.t ELSE highest
       /\ stval' = IF acc THEN m.v ELSE stval
       /\ writeMsgs' = IF dup THEN writeMsgs ELSE writeMsgs \ {m}
       /\ dups' = IF dup THEN dups + 1 ELSE dups
       /\ decisions' = Append(decisions, [token |-> m.t, hb |-> highest, outcome |-> out,
                                          client |-> m.c, value |-> m.v, term |-> m.g, sv |-> stval])
       /\ toAck' = toAck \cup {[c |-> m.c, t |-> m.t, g |-> m.g, v |-> m.v, outcome |-> out]}
       /\ UNCHANGED <<up, paused, down, promised, maxTok, leader, term, ltok, reqs,
                      pending, tok, myToks, awaiting, grantMsgs, ackMsgs, grants, rq, issued, told>>
       /\ Emit(<<[event |-> IF acc THEN "WriteAccept" ELSE "WriteReject", key |-> Key,
                  token |-> m.t, highest_before |-> highest, grantor_term |-> m.g,
                  client |-> m.c, value |-> m.v, stored_value |-> stval]>>)

\* derives: C1.3, F1.1, F1.2, F2.1, F2.2 -- storage sends a queued ack (lost if the link
\* storage->client is down or the client is down, at the moment it is sent)
SendAck(a) ==
    /\ UNCHANGED rvars  \* derives: C2.1, C2.2 -- reads untouched
    /\ UNCHANGED kvars
    /\ UNCHANGED xvars
    /\ up[Store]
    /\ a \in toAck
    /\ toAck' = toAck \ {a}
    /\ ackMsgs' = IF Link(Store, a.c) /\ up[a.c] THEN ackMsgs \cup {a} ELSE ackMsgs
    /\ UNCHANGED <<up, paused, down, promised, maxTok, leader, term, ltok, reqs, pending,
                   tok, myToks, awaiting, grantMsgs, writeMsgs, dups, highest, stval,
                   grants, rq, issued, decisions, told>>
    /\ Internal("SendAck", Store)

\* derives: C1.3, F1.3 -- a client receives an ack for a write it is awaiting
\* and is told the write's outcome exactly as the ack states it.
RecvAck(a) ==
    /\ UNCHANGED rvars  \* derives: C2.1, C2.2 -- reads untouched
    /\ UNCHANGED kvars
    /\ UNCHANGED xvars
    /\ a \in ackMsgs
    /\ up[a.c] /\ ~paused[a.c]
    /\ ackMsgs' = ackMsgs \ {a}
    /\ LET w == [t |-> a.t, g |-> a.g, v |-> a.v] IN
       IF w \in awaiting[a.c]
       THEN /\ awaiting' = [awaiting EXCEPT ![a.c] = @ \ {w}]
            /\ told' = IF a.outcome = "accept" THEN told \cup {[c |-> a.c, t |-> a.t, v |-> a.v]}
                       ELSE told
            /\ UNCHANGED <<up, paused, down, promised, maxTok, leader, term, ltok, reqs,
                           pending, tok, myToks, grantMsgs, writeMsgs, dups, highest,
                           stval, toAck, grants, rq, issued, decisions>>
            /\ Emit(<<[event |-> "WriteAck", client |-> a.c, key |-> Key, token |-> a.t,
                       outcome |-> IF a.outcome = "accept" THEN "accepted" ELSE "rejected",
                       value |-> a.v, grantor_term |-> a.g]>>)
       ELSE /\ UNCHANGED <<up, paused, down, promised, maxTok, leader, term, ltok, reqs,
                           pending, tok, myToks, awaiting, grantMsgs, writeMsgs, dups,
                           highest, stval, toAck, grants, rq, issued, decisions, told>>
            /\ Internal("DropAck", a.c)

\* ===========================================================================
\* Schedule steps: workload (derives from the contract) and faults (one per cell)
\* ===========================================================================

\* derives: F1.1, F1.2, F1.3; format v2.1 A1, v5 R1 -- resolve "grantor"/"holder"/"non-grantor"/"non-member"
\* at trigger time. format v2.1 A1: `non-grantor` resolves to ng, one of the candidates chosen by
\* ScheduleStep; format v5 R1: `non-member` resolves to nm, likewise
Resolve(x, ng, nm) == IF x = "grantor" THEN trigG.node
                      ELSE IF x = "holder" THEN trigG.client
                      ELSE IF x = "non-grantor" THEN ng
                      ELSE IF x = "non-member" THEN nm ELSE x

\* derives: C1.2, F1.3 -- the client's most recent superseded token (lower than the highest granted)
StaleTok(c) ==
    LET S == {x \in myToks[c] : x.t < MaxGranted} IN
    IF S = {} THEN NoTok ELSE CHOOSE x \in S : \A y \in S : y.t <= x.t

\* derives: C1.4 -- workload: client requests a grant (a client already waiting for
\* a grant does not issue a second request; the step waits until it is not waiting)
DoRequest(c) ==
    /\ UNCHANGED rvars  \* derives: C2.1, C2.2 -- reads untouched
    /\ UNCHANGED kvars
    /\ UNCHANGED xvars
    /\ up[c] /\ ~paused[c]
    /\ ~pending[c]
    /\ pending' = [pending EXCEPT ![c] = TRUE]
    /\ reqs' = reqs \cup {c}
    /\ rq' = [rq EXCEPT ![c] = @ + 1]   \* derives: C1.4 -- a new request
    /\ UNCHANGED <<up, paused, down, promised, maxTok, leader, term, ltok, tok, myToks,
                   awaiting, grantMsgs, writeMsgs, ackMsgs, dups, highest, stval, toAck,
                   grants, issued, decisions, told>>
    /\ lastEv' = <<[event |-> "Request", client |-> c, key |-> Key]>>

\* derives: C1.2, C1.3, F1.3, F2.1, F2.2 -- workload: client writes with its current (or stale)
\* token; the write is lost if client->storage is down when it is sent
DoWrite(c, v, stale) ==
    LET k == IF stale THEN StaleTok(c) ELSE tok[c] IN
    /\ UNCHANGED rvars  \* derives: C2.1, C2.2 -- reads untouched
    /\ UNCHANGED kvars
    /\ UNCHANGED xvars
    /\ up[c] /\ ~paused[c]
    /\ k.t > 0
    /\ writeMsgs' = IF Link(c, Store) /\ up[Store]
                    THEN writeMsgs \cup {[c |-> c, t |-> k.t, g |-> k.g, v |-> v]}
                    ELSE writeMsgs
    /\ awaiting' = [awaiting EXCEPT ![c] = @ \cup {[t |-> k.t, g |-> k.g, v |-> v]}]
    /\ UNCHANGED <<up, paused, down, promised, maxTok, leader, term, ltok, reqs, pending,
                   tok, myToks, grantMsgs, ackMsgs, dups, highest, stval, toAck,
                   grants, rq, issued, decisions, told>>
    /\ lastEv' = <<[event |-> "WriteAttempt", client |-> c, key |-> Key, token |-> k.t,
                    value |-> v, grantor_term |-> k.g]>>

\* derives: C3.4, F3.1; format v5 R1 -- an operator sends a reconfiguration request to receiver x. It is a
\* message: lost if o->x is down (or x is down) when it is sent. Not a fault.
DoReconfig(o, rid, mem, x) ==
    /\ UNCHANGED rvars
    /\ UNCHANGED <<inc, cfg, jprop, pend, owed, opMsgs, commits, refusals, opTold, xvars>>
    /\ x \in Nodes
    /\ rcMsgs' = IF Link(o, x) /\ up[x] THEN rcMsgs \cup {[op |-> o, rid |-> rid, mem |-> mem, to |-> x]}
                 ELSE rcMsgs
    /\ UNCHANGED <<up, paused, down, promised, maxTok, leader, term, ltok, reqs, pending, tok,
                   myToks, awaiting, grantMsgs, writeMsgs, ackMsgs, dups, highest, stval,
                   toAck, grants, rq, issued, decisions, told>>
    /\ lastEv' = <<[event |-> "ReconfigSend", operator |-> o, request_id |-> rid, to |-> x, members |-> mem]>>

\* ===========================================================================
\* Reads (contract v2, X1)
\* ===========================================================================

\* derives: C2.1, C2.2, F1.1, C3.5 -- storage decides a read: serve iff token >= ledger, returning
\* the value it holds; the ledger is not changed. The ack is queued (volatile).
\* dup = TRUE models a duplicated delivery (bounded by MaxDups, shared with writes).
StorageRead(m, dup) ==
    /\ UNCHANGED kvars
    /\ UNCHANGED xvars
    /\ up[Store]
    /\ m \in readMsgs
    /\ dup => dups < MaxDups
    /\ LET srv == m.t >= highest
           out == IF srv THEN "served" ELSE "rejected"
           val == IF srv THEN stval ELSE "none" IN
       /\ UNCHANGED <<rAckMsgs, awaitingR, given>>
       /\ UNCHANGED <<up, paused, down, promised, maxTok, leader, term, ltok, reqs,
                      pending, tok, myToks, awaiting, grantMsgs, writeMsgs, ackMsgs,
                      highest, stval, toAck, grants, rq, issued, decisions, told>>
       /\ readMsgs' = IF dup THEN readMsgs ELSE readMsgs \ {m}
       /\ dups' = IF dup THEN dups + 1 ELSE dups
       /\ rdecisions' = Append(rdecisions,
                [token |-> m.t, hb |-> highest, ha |-> highest', outcome |-> out, client |-> m.c,
                 rid |-> m.r, value |-> val, held |-> stval, nwrites |-> Len(decisions)])
       /\ rToAck' = rToAck \cup {[c |-> m.c, t |-> m.t, g |-> m.g, r |-> m.r,
                                  outcome |-> out, v |-> val]}
       /\ Emit(IF srv
                THEN <<[event |-> "ReadAccept", key |-> Key, token |-> m.t, highest_before |-> highest,
                        value |-> val, grantor_term |-> m.g, client |-> m.c, rid |-> m.r,
                        stored_value |-> stval]>>
                ELSE <<[event |-> "ReadReject", key |-> Key, token |-> m.t, highest_before |-> highest,
                        grantor_term |-> m.g, client |-> m.c, rid |-> m.r, stored_value |-> stval]>>)

\* derives: C2.2, F1.1, F1.2, F2.1, F2.2 -- storage sends a queued read ack (lost if the link
\* storage->client is down or the client is down, at the moment it is sent)
SendReadAck(a) ==
    /\ UNCHANGED kvars
    /\ UNCHANGED xvars
    /\ up[Store]
    /\ a \in rToAck
    /\ rToAck' = rToAck \ {a}
    /\ rAckMsgs' = IF Link(Store, a.c) /\ up[a.c] THEN rAckMsgs \cup {a} ELSE rAckMsgs
    /\ UNCHANGED <<readMsgs, awaitingR, rdecisions, given>>
    /\ UNCHANGED <<up, paused, down, promised, maxTok, leader, term, ltok, reqs, pending,
                   tok, myToks, awaiting, grantMsgs, writeMsgs, ackMsgs, dups, highest, stval,
                   toAck, grants, rq, issued, decisions, told>>
    /\ Internal("SendReadAck", Store)

\* derives: C2.2, F1.3 -- a client receives an ack for a read it is awaiting and is given
\* exactly the value the ack carries (only when the ack says served)
RecvReadAck(a) ==
    /\ UNCHANGED kvars
    /\ UNCHANGED xvars
    /\ a \in rAckMsgs
    /\ up[a.c] /\ ~paused[a.c]
    /\ rAckMsgs' = rAckMsgs \ {a}
    /\ UNCHANGED <<readMsgs, rToAck, rdecisions>>
    /\ UNCHANGED <<up, paused, down, promised, maxTok, leader, term, ltok, reqs, pending,
                   tok, myToks, awaiting, grantMsgs, writeMsgs, ackMsgs, dups, highest, stval,
                   toAck, grants, rq, issued, decisions, told>>
    /\ LET w == [t |-> a.t, g |-> a.g, r |-> a.r] IN
       IF w \in awaitingR[a.c]
       THEN /\ awaitingR' = [awaitingR EXCEPT ![a.c] = @ \ {w}]
            /\ given' = IF a.outcome = "served"
                        THEN given \cup {[c |-> a.c, t |-> a.t, r |-> a.r, v |-> a.v]} ELSE given
            /\ Emit(IF a.outcome = "served"
                     THEN <<[event |-> "ReadAck", client |-> a.c, key |-> Key, token |-> a.t,
                             outcome |-> "served", value |-> a.v, grantor_term |-> a.g, rid |-> a.r]>>
                     ELSE <<[event |-> "ReadAck", client |-> a.c, key |-> Key, token |-> a.t,
                             outcome |-> "rejected", grantor_term |-> a.g, rid |-> a.r]>>)
       ELSE /\ UNCHANGED <<awaitingR, given>>
            /\ Internal("DropReadAck", a.c)

\* derives: C2.1, C2.2, F1.3, F2.1, F2.2; format v3 (read), v2 T3 -- workload: client reads with its current
\* (or stale) token; waits as for a write. The read id is the schedule step index.
DoRead(c, stale) ==
    LET k == IF stale THEN StaleTok(c) ELSE tok[c] IN
    /\ UNCHANGED kvars
    /\ UNCHANGED xvars
    /\ up[c] /\ ~paused[c]
    /\ k.t > 0
    /\ readMsgs' = IF Link(c, Store) /\ up[Store]
                   THEN readMsgs \cup {[c |-> c, t |-> k.t, g |-> k.g, r |-> pc]}
                   ELSE readMsgs
    /\ awaitingR' = [awaitingR EXCEPT ![c] = @ \cup {[t |-> k.t, g |-> k.g, r |-> pc]}]
    /\ UNCHANGED <<rToAck, rAckMsgs, rdecisions, given>>
    /\ UNCHANGED <<up, paused, down, promised, maxTok, leader, term, ltok, reqs, pending,
                   tok, myToks, awaiting, grantMsgs, writeMsgs, ackMsgs, dups, highest, stval,
                   toAck, grants, rq, issued, decisions, told>>
    /\ lastEv' = <<[event |-> "ReadAttempt", client |-> c, key |-> Key, token |-> k.t,
                    grantor_term |-> k.g, rid |-> pc]>>

\* derives: F1.1 -- crash-stop: volatile state lost, durable state kept, messages to p lost
\* X3 (derives: F1.1, F3.2, C3.4): a lease node's timers restart with it (early cleared), and
\* reconfiguration requests in flight to it are lost with its inbox; its pending request and
\* owed replies are durable.
Crash(p) ==
    /\ up[p]
    /\ p \notin Ops   \* derives: C3.4 -- an operator does not crash (contract v3 "Operator")
    /\ up' = [up EXCEPT ![p] = FALSE]
    /\ IF p \in Nodes
       THEN /\ leader' = [leader EXCEPT ![p] = FALSE]
            /\ term' = [term EXCEPT ![p] = 0]
            /\ ltok' = [ltok EXCEPT ![p] = 0]
            /\ UNCHANGED <<paused, reqs, pending, tok, myToks, awaiting, grantMsgs,
                           writeMsgs, ackMsgs, toAck>>
            /\ UNCHANGED <<readMsgs, rToAck, rAckMsgs, awaitingR>>
            /\ early' = [early EXCEPT ![p] = FALSE]
            /\ rcMsgs' = {m \in rcMsgs : m.to # p}
       ELSE IF p \in Clients
       THEN /\ paused' = [paused EXCEPT ![p] = FALSE]
            /\ reqs' = reqs \ {p}
            /\ pending' = [pending EXCEPT ![p] = FALSE]
            /\ tok' = [tok EXCEPT ![p] = NoTok]
            /\ myToks' = [myToks EXCEPT ![p] = {}]
            /\ awaiting' = [awaiting EXCEPT ![p] = {}]
            /\ grantMsgs' = {m \in grantMsgs : m.c # p}
            /\ ackMsgs' = {a \in ackMsgs : a.c # p}
            /\ UNCHANGED <<leader, term, ltok, writeMsgs, toAck>>
            \* derives: C2.2, F1.1 -- a crashed client loses its read acks and awaited reads
            /\ rAckMsgs' = {a \in rAckMsgs : a.c # p}
            /\ awaitingR' = [awaitingR EXCEPT ![p] = {}]
            /\ UNCHANGED <<readMsgs, rToAck>>
            /\ UNCHANGED <<early, rcMsgs>>
       ELSE \* storage
            /\ writeMsgs' = {}
            /\ toAck' = {}
            /\ UNCHANGED <<leader, term, ltok, paused, reqs, pending, tok, myToks,
                           awaiting, grantMsgs, ackMsgs>>
            \* derives: C2.1, C2.2, F1.1 -- storage loses in-flight reads and unsent read acks
            /\ readMsgs' = {}
            /\ rToAck' = {}
            /\ UNCHANGED <<rAckMsgs, awaitingR>>
            /\ UNCHANGED <<early, rcMsgs>>
    /\ UNCHANGED <<down, promised, maxTok, dups, highest, stval, grants, rq, issued, decisions, told>>
    /\ UNCHANGED <<rdecisions, given>>
    /\ UNCHANGED <<inc, cfg, jprop, pend, owed, opMsgs, commits, refusals, opTold, off, agreeLog>>
    /\ lastEv' = <<[event |-> "Fault", cell |-> "F1.1", action |-> "crash", target |-> p]>>

\* derives: F1.1 -- restart with durable state only (a restarted client has no grant)
\* X3 (derives: F1.1, F3.3): this is the ordinary restart, which keeps a lease node's durable state and its
\* incarnation (contract v3 "Incarnation"); a restart with no durable state is AmnesicRestart (F3.3)
Restart(p) ==
    /\ UNCHANGED rvars  \* derives: C2.1, C2.2 -- reads untouched
    /\ UNCHANGED kvars
    /\ UNCHANGED xvars
    /\ ~up[p]
    /\ up' = [up EXCEPT ![p] = TRUE]
    /\ UNCHANGED <<paused, down, promised, maxTok, leader, term, ltok, reqs, pending, tok,
                   myToks, awaiting, grantMsgs, writeMsgs, ackMsgs, dups, highest, stval,
                   toAck, grants, rq, issued, decisions, told>>
    /\ lastEv' = <<[event |-> "Fault", cell |-> "F1.1", action |-> "restart", target |-> p]>>

\* derives: F3.3, C3.7, C3.8, C1.1; format v5 R3 -- amnesic restart of a crashed lease node: a new
\* incarnation with no durable state. It keeps what the deployment gives every node (its name,
\* the lease nodes, the initial configuration, L): its configuration history is the deployment's
\* epoch 0, unrecorded. Its pending request and owed replies are gone (contract v3 "Pending").
AmnesicRestart(n) ==
    /\ UNCHANGED rvars
    /\ UNCHANGED <<rcMsgs, opMsgs, commits, refusals, opTold, xvars>>
    /\ n \in Nodes /\ ~up[n]
    /\ up' = [up EXCEPT ![n] = TRUE]
    /\ inc' = [inc EXCEPT ![n] = @ + 1]
    /\ promised' = [promised EXCEPT ![n] = 0]
    /\ maxTok' = [maxTok EXCEPT ![n] = 0]
    /\ cfg' = [cfg EXCEPT ![n] = <<Init0Rec>>]
    /\ jprop' = [jprop EXCEPT ![n] = NoConf]
    /\ pend' = [pend EXCEPT ![n] = NoPend]
    /\ owed' = [owed EXCEPT ![n] = {}]
    /\ UNCHANGED <<paused, down, leader, term, ltok, reqs, pending, tok,
                   myToks, awaiting, grantMsgs, writeMsgs, ackMsgs, dups, highest, stval,
                   toAck, grants, rq, issued, decisions, told>>
    /\ lastEv' = <<[event |-> "Fault", cell |-> "F3.3", action |-> "restart", target |-> n, amnesia |-> TRUE]>>

\* derives: F3.2, C1.4; format v5 R2 -- p's clock steps by s ticks (s = step x L). A forward step on a
\* running lease node may fire its timers early; a backward step only delays them, which the
\* untimed failure detector (HearsLeader) already allows, so it enables nothing new.
ClockStep(p, s) ==
    /\ UNCHANGED rvars
    /\ UNCHANGED kvars
    /\ UNCHANGED agreeLog
    /\ off' = [off EXCEPT ![p] = @ + s]
    /\ early' = IF p \in Nodes /\ s > 0 /\ up[p] THEN [early EXCEPT ![p] = TRUE] ELSE early
    /\ UNCHANGED <<up, paused, down, promised, maxTok, leader, term, ltok, reqs, pending, tok,
                   myToks, awaiting, grantMsgs, writeMsgs, ackMsgs, dups, highest, stval,
                   toAck, grants, rq, issued, decisions, told>>
    /\ lastEv' = <<[event |-> "Fault", cell |-> "F3.2", action |-> "clock", target |-> p, step |-> s]>>

\* derives: F1.2, F2.1 -- complete bipartition: every link between the two sides goes down in
\* both directions (F2.1: "F1.2 is the special case in which the down links are exactly
\* those between two sides"). Link failures accumulate (format v4 L2).
\* X2: messages already in flight are not dropped (failure model v2: a message's fate is
\* fixed when it is sent). This replaces v1 interpretation 13 (README, X2).
Partition(A) ==
    /\ UNCHANGED rvars  \* derives: C2.1, C2.2 -- reads untouched (in-flight reads keep their fate)
    /\ UNCHANGED kvars
    /\ UNCHANGED xvars
    /\ A # {} /\ A # Procs
    /\ down' = down \cup {x \in Procs \X Procs : (x[1] \in A) # (x[2] \in A)}
    /\ UNCHANGED <<up, paused, promised, maxTok, leader, term, ltok, reqs, pending, tok,
                   myToks, awaiting, grantMsgs, writeMsgs, ackMsgs, dups, highest, stval,
                   toAck, grants, rq, issued, decisions, told>>
    /\ lastEv' = <<[event |-> "Fault", cell |-> "F1.2", action |-> "partition", sideA |-> A]>>

\* derives: F2.1; format v4 cut, L1, L2 -- partial partition: each listed link goes down in both
\* directions (L is the listed pairs, already resolved, self-pairs removed)
Cut(L) ==
    /\ UNCHANGED rvars  \* derives: C2.1, C2.2 -- reads untouched
    /\ UNCHANGED kvars
    /\ UNCHANGED xvars
    /\ down' = down \cup BothWays(L)
    /\ UNCHANGED <<up, paused, promised, maxTok, leader, term, ltok, reqs, pending, tok,
                   myToks, awaiting, grantMsgs, writeMsgs, ackMsgs, dups, highest, stval,
                   toAck, grants, rq, issued, decisions, told>>
    /\ lastEv' = <<[event |-> "Fault", cell |-> "F2.1", action |-> "cut", pairs |-> L, links |-> BothWays(L)]>>

\* derives: F2.2; format v4 drop, L1, L2 -- simplex link failure: each listed link goes down in
\* the listed direction only (L is already resolved, self-pairs removed)
Drop(L) ==
    /\ UNCHANGED rvars  \* derives: C2.1, C2.2 -- reads untouched
    /\ UNCHANGED kvars
    /\ UNCHANGED xvars
    /\ down' = down \cup L
    /\ UNCHANGED <<up, paused, promised, maxTok, leader, term, ltok, reqs, pending, tok,
                   myToks, awaiting, grantMsgs, writeMsgs, ackMsgs, dups, highest, stval,
                   toAck, grants, rq, issued, decisions, told>>
    /\ lastEv' = <<[event |-> "Fault", cell |-> "F2.2", action |-> "drop", pairs |-> L, links |-> L]>>

\* derives: F1.2, F2.1, F2.2; format v4 L2 -- a heal, whichever cell it names, restores every
\* link; lost messages stay lost
Heal(cell) ==
    /\ UNCHANGED rvars  \* derives: C2.1, C2.2 -- reads untouched
    /\ UNCHANGED kvars
    /\ UNCHANGED xvars
    /\ down' = {}
    /\ UNCHANGED <<up, paused, promised, maxTok, leader, term, ltok, reqs, pending, tok,
                   myToks, awaiting, grantMsgs, writeMsgs, ackMsgs, dups, highest, stval,
                   toAck, grants, rq, issued, decisions, told>>
    /\ lastEv' = <<[event |-> "Fault", cell |-> cell, action |-> "heal", target |-> "all"]>>

\* derives: F1.3 -- holder pause: the client takes no steps; the rest of the world proceeds
Pause(c) ==
    /\ UNCHANGED rvars  \* derives: C2.1, C2.2 -- reads untouched
    /\ UNCHANGED kvars
    /\ UNCHANGED xvars
    /\ up[c] /\ ~paused[c]
    /\ paused' = [paused EXCEPT ![c] = TRUE]
    /\ UNCHANGED <<up, down, promised, maxTok, leader, term, ltok, reqs, pending, tok,
                   myToks, awaiting, grantMsgs, writeMsgs, ackMsgs, dups, highest, stval,
                   toAck, grants, rq, issued, decisions, told>>
    /\ lastEv' = <<[event |-> "Fault", cell |-> "F1.3", action |-> "pause", target |-> c]>>

\* derives: F1.3 -- resume as if no time had passed (the client keeps its old token)
Resume(c) ==
    /\ UNCHANGED rvars  \* derives: C2.1, C2.2 -- reads untouched
    /\ UNCHANGED kvars
    /\ UNCHANGED xvars
    /\ paused[c]
    /\ paused' = [paused EXCEPT ![c] = FALSE]
    /\ UNCHANGED <<up, down, promised, maxTok, leader, term, ltok, reqs, pending, tok,
                   myToks, awaiting, grantMsgs, writeMsgs, ackMsgs, dups, highest, stval,
                   toAck, grants, rq, issued, decisions, told>>
    /\ lastEv' = <<[event |-> "Fault", cell |-> "F1.3", action |-> "resume", target |-> c]>>

\* derives: F1.2 -- the side of a partition step, after resolving grantor/holder/rest
SideOf(st, ng, nm) ==
    LET a == {Resolve(x, ng, nm) : x \in st.a \ {"rest"}}
        b == {Resolve(x, ng, nm) : x \in st.b \ {"rest"}} IN
    IF "rest" \in st.a THEN Procs \ b ELSE a

\* derives: F2.1, F2.2; format v4 L1 -- the names in a step's link list (both ends of every pair)
LinkNames(st) == {e[1] : e \in st.l} \cup {e[2] : e \in st.l}

\* derives: F2.1, F2.2; format v4 L1 -- the directed links a `cut`/`drop` step names, selectors
\* resolved, self-pairs removed (a pair whose ends resolve to one process is ignored)
StepLinks(st, ng, nm) == {<<Resolve(e[1], ng, nm), Resolve(e[2], ng, nm)>> : e \in st.l}
                         \ {<<p, p>> : p \in Procs}

\* derives: F1.1, F1.2, F1.3, F2.1, F2.2; format v2 A1, v4 L1 -- every alias in the step resolved
\* to a process (an alias that names no Grant yet leaves the step waiting; the compiler
\* rejects the statically detectable cases)
Resolved(st, ng, nm) == /\ st.p = "none" \/ Resolve(st.p, ng, nm) \in Procs
                        /\ \A x \in (st.a \cup st.b) \ {"rest"} : Resolve(x, ng, nm) \in Procs
                        /\ \A x \in LinkNames(st) : Resolve(x, ng, nm) \in Procs

\* derives: C1.2, C1.4, F1.1, F1.2, F1.3, F2.1, F2.2, F3.1, F3.2, F3.3; format v2 A1, T3, v4 cut, drop, v5 -- the effect of one schedule step
\* (each workload action's own guard makes it wait as T3 requires)
DoStep(st, ng, nm) ==
    /\ Resolved(st, ng, nm)
    /\ CASE st.kind = "request"   -> DoRequest(Resolve(st.p, ng, nm))
      [] st.kind = "write"     -> DoWrite(Resolve(st.p, ng, nm), st.v, st.stale)
      [] st.kind = "read"      -> DoRead(Resolve(st.p, ng, nm), st.stale)   \* derives: C2.1, C2.2
      [] st.kind = "crash"     -> Crash(Resolve(st.p, ng, nm))
      [] st.kind = "restart"   -> Restart(Resolve(st.p, ng, nm))
      [] st.kind = "partition" -> Partition(SideOf(st, ng, nm))
      [] st.kind = "heal"      -> Heal(st.cell)                          \* derives: F1.2, F2.1, F2.2
      [] st.kind = "cut"       -> Cut(StepLinks(st, ng, nm))            \* derives: F2.1
      [] st.kind = "drop"      -> Drop(StepLinks(st, ng, nm))           \* derives: F2.2
      [] st.kind = "pause"     -> Pause(Resolve(st.p, ng, nm))
      [] st.kind = "resume"    -> Resume(Resolve(st.p, ng, nm))
      [] st.kind = "reconfig"  -> DoReconfig(st.op, st.rid, st.mem, Resolve(st.p, ng, nm))   \* derives: F3.1
      [] st.kind = "clock"     -> ClockStep(Resolve(st.p, ng, nm), st.s)                   \* derives: F3.2
      [] st.kind = "amnesia"   -> AmnesicRestart(Resolve(st.p, ng, nm))                     \* derives: F3.3

\* derives: F1.1; format v2.1 A1 -- candidate resolutions of `non-grantor` for step st
\* format v2.1 T1: the next trigger is offered lastEv', the events this step's own action emitted
\* synchronously, so a step may be triggered by its predecessor's own event.
\* format v2.1 A1: `non-grantor` is explored over every candidate (the lease nodes other than
\* grantor that were up when the trigger fired); `restart: non-grantor` names the node the most
\* recent `crash: non-grantor` crashed, whether or not it is a non-grantor now (format v2.2 A1).
\* derives: F2.1, F2.2; format v4 L1 -- `non-grantor` may also stand in a link
\* derives: F3.3; format v5 R3 -- an amnesic restart of `non-grantor` is a restart (names ngDown)
NGChoices(st) ==
    IF "non-grantor" \notin ({st.p} \cup st.a \cup st.b \cup LinkNames(st)) THEN {"none"}
    ELSE IF st.kind \in {"restart", "amnesia"} THEN {ngDown}
    ELSE trigNG
\* derives: F3.1; format v5 R1 -- candidate resolutions of `non-member` (every one is explored)
NMChoices(st) ==
    IF "non-member" \notin ({st.p} \cup st.a \cup st.b \cup LinkNames(st)) THEN {"none"} ELSE trigNM

\* derives: F1.1, F1.2, F1.3; format v2.1 T1, A1 -- apply step pc once its trigger has held; arm the next trigger
ScheduleStep ==
    /\ pc <= Len(Steps)
    /\ fired
    /\ \E ng \in NGChoices(Steps[pc]), nm \in NMChoices(Steps[pc]) :
        /\ DoStep(Steps[pc], ng, nm)
        /\ ngDown' = IF Steps[pc].kind = "crash" /\ Steps[pc].p = "non-grantor" THEN ng ELSE ngDown
    /\ pc' = pc + 1
    /\ fired' = (IsStart(Trig(pc + 1)) \/ Matches(Trig(pc + 1), lastEv'))
    /\ trigG' = IF fired' THEN LastGrant ELSE trigG
    /\ trigNG' = IF fired' THEN {n \in Nodes : up'[n]} \ {LastGrant.node} ELSE trigNG
    /\ trigNM' = IF fired' THEN NonMembers ELSE trigNM

\* ===========================================================================
\* derives: C1.1, C1.2, C1.3, C1.4, F1.1, F1.2, F1.3, F2.1, F2.2, C3.x, F3.x
Protocol ==
    \/ \E n \in Nodes : Elect(n) \/ StepDown(n)
    \/ \E n \in Nodes : CheckQuorum(n)   \* derives: C1.4, F2.2
    \/ \E n \in Nodes : Join(n)
    \/ \E n \in Nodes, c \in Clients : Grant(n, c)
    \/ \E n \in Nodes, c \in Clients : Resend(n, c)   \* derives: C1.4, F2.2
    \/ \E m \in grantMsgs : RecvGrant(m)
    \/ \E m \in writeMsgs, d \in BOOLEAN : StorageDecide(m, d)
    \/ \E a \in toAck : SendAck(a)
    \/ \E a \in ackMsgs : RecvAck(a)
    \/ \E m \in readMsgs, d \in BOOLEAN : StorageRead(m, d)   \* derives: C2.1, C2.2
    \/ \E a \in rToAck : SendReadAck(a)                       \* derives: C2.2
    \/ \E a \in rAckMsgs : RecvReadAck(a)                     \* derives: C2.2
    \/ \E l, x \in Nodes : Commit(l, x)                       \* derives: C3.1, C3.8, F3.1
    \/ \E n, m \in Nodes : LearnConfig(n, m)                  \* derives: C3.1, C3.4, F3.1
    \/ \E m \in rcMsgs : RecvReconfig(m)                      \* derives: C3.4, F3.1
    \/ \E x \in Nodes : \E a \in owed[x] : ReplyOp(x, a)      \* derives: C3.4, C3.8

\* derives: C1.1, C1.2, C1.3, C1.4, F1.1, F1.2, F1.3
Next == Protocol \/ ScheduleStep

\* derives: C1.4, C3.4 -- the steps Fairness makes fair: every protocol action but a duplicated delivery, and
\* the schedule (README X3, "Fairness (X3)")
FairNext ==
    \/ \E n \in Nodes : Elect(n) \/ StepDown(n) \/ CheckQuorum(n) \/ Join(n)
    \/ \E n \in Nodes, c \in Clients : Grant(n, c) \/ Resend(n, c)
    \/ \E m \in grantMsgs : RecvGrant(m)
    \/ \E m \in writeMsgs : StorageDecide(m, FALSE)
    \/ \E a \in toAck : SendAck(a)
    \/ \E a \in ackMsgs : RecvAck(a)
    \/ \E m \in readMsgs : StorageRead(m, FALSE)
    \/ \E a \in rToAck : SendReadAck(a)
    \/ \E a \in rAckMsgs : RecvReadAck(a)
    \/ \E l, x \in Nodes : Commit(l, x)
    \/ \E n, m \in Nodes : LearnConfig(n, m)
    \/ \E m \in rcMsgs : RecvReconfig(m)
    \/ \E x \in Nodes : \E a \in owed[x] : ReplyOp(x, a)
    \/ ScheduleStep

\* derives: C1.4 -- weak fairness on every protocol action and on the schedule
\* (the environment does eventually perform each scheduled step whose trigger held).
\* X2: every condition is named, with its justification, in README "Fairness (X2)". Each
\* protocol action's enablement depends only on the acting process's own state and on
\* messages over links that are up; none requires hearing a peer over a down link.
\* X3: the new conditions are named in README "Fairness (X3)", with the same justification.
Fairness ==
    /\ \A n \in Nodes : WF_vars(Elect(n)) /\ WF_vars(StepDown(n))
    /\ \A n \in Nodes : WF_vars(CheckQuorum(n))  \* derives: C1.4, F2.2 (own timer only)
    /\ \A n \in Nodes : WF_vars(Join(n))  \* derives: C1.4, F1.1 (P10 fix)
    /\ \A n \in Nodes, c \in Clients : WF_vars(Grant(n, c))
    /\ \A n \in Nodes, c \in Clients : WF_vars(Resend(n, c))  \* derives: C1.4, F2.2 (routing fix)
    /\ WF_vars(\E m \in grantMsgs : RecvGrant(m))
    /\ WF_vars(\E m \in writeMsgs : StorageDecide(m, FALSE))
    /\ WF_vars(\E a \in toAck : SendAck(a))
    /\ WF_vars(\E a \in ackMsgs : RecvAck(a))
    /\ WF_vars(\E m \in readMsgs : StorageRead(m, FALSE))   \* derives: C2.1, C2.2
    /\ WF_vars(\E a \in rToAck : SendReadAck(a))            \* derives: C2.2
    /\ WF_vars(\E a \in rAckMsgs : RecvReadAck(a))          \* derives: C2.2
    /\ \A l \in Nodes : WF_vars(\E x \in Nodes : Commit(l, x))        \* derives: C3.4, F3.1
    /\ \A n \in Nodes : WF_vars(\E m \in Nodes : LearnConfig(n, m))   \* derives: C3.4, C1.4, F3.1
    /\ WF_vars(\E m \in rcMsgs : RecvReconfig(m))                     \* derives: C3.4
    /\ \A x \in Nodes : WF_vars(\E a \in owed[x] : ReplyOp(x, a))     \* derives: C3.4
    /\ WF_vars(ScheduleStep)

Spec == Init /\ [][Next]_vars /\ Fairness

\* derives: C1.1, C1.2, C1.3 -- shape of the state (catches modelling errors, not a clause)
TypeOK ==
    /\ up \in [Procs -> BOOLEAN]

\* derives: C1.1 (contract v3, "C1.1 across configurations") -- v3's reading, without a global order:
\* (a) no two grants carry one token; (b) a grant under a higher configuration epoch carries a higher
\* token than every grant under a lower one; (c) each node's counted agreements to grants, in its own
\* order, carry strictly increasing tokens.
C1_1 == /\ \A i, j \in 1..Len(grants) : i # j => grants[i].token # grants[j].token
        /\ \A i, j \in 1..Len(grants) : grants[i].ep < grants[j].ep => grants[i].token < grants[j].token
        /\ \A n \in Nodes : \A i, j \in 1..Len(agreeLog[n]) : i < j => agreeLog[n][i].t < agreeLog[n][j].t

\* derives: C1.1 (v1 reading, kept; README X3) -- each grant's token is strictly greater than every
\* earlier grant's in the model's total order. Not v3's reading: a violation of this alone is reported
\* UNEXPLAINED, not FAIL.
C1_1order == \A i, j \in 1..Len(grants) : i < j => grants[i].token < grants[j].token

\* derives: C1.1, C3.7 (contract v3 "Grantor term") -- two grants with one term were decided by the same
\* incarnation of the same node
TermUnique == \A i, j \in 1..Len(grants) :
                grants[i].term = grants[j].term => grants[i].node = grants[j].node /\ grants[i].ninc = grants[j].ninc

\* derives: C1.2 -- storage accepts only tokens >= every token it accepted before
\* (stated over the decision history, not over storage's own ledger variable, so a
\* ledger that forgets is caught; the ledger update is implied by this)
C1_2 == \A i \in 1..Len(decisions) :
          decisions[i].outcome = "accept" =>
            \A j \in 1..(i - 1) : decisions[j].outcome = "accept" =>
                                    decisions[j].token <= decisions[i].token

\* derives: C1.3 -- every write a client was told succeeded was accepted by storage
C1_3 == \A x \in told : \E i \in 1..Len(decisions) :
          /\ decisions[i].outcome = "accept"
          /\ decisions[i].client = x.c
          /\ decisions[i].token = x.t
          /\ decisions[i].value = x.v

\* derives: C2.1 -- every served read's token is >= every token a write was accepted with
\* before it (over history, not over storage's ledger), and a read decision leaves the
\* ledger unchanged
C2_1 == \A i \in 1..Len(rdecisions) :
          /\ rdecisions[i].outcome = "served" =>
               \A j \in 1..rdecisions[i].nwrites :
                  decisions[j].outcome = "accept" => decisions[j].token <= rdecisions[i].token
          /\ rdecisions[i].ha = rdecisions[i].hb

\* derives: C2.2 -- every value a client was given was returned by an earlier serve of that
\* very read (client, token, read id), and equals what storage held when it served
C2_2 == \A x \in given : \E i \in 1..Len(rdecisions) :
          /\ rdecisions[i].outcome = "served"
          /\ rdecisions[i].client = x.c
          /\ rdecisions[i].token = x.t
          /\ rdecisions[i].rid = x.r
          /\ rdecisions[i].value = x.v
          /\ rdecisions[i].held = x.v

\* derives: C3.1 -- epoch e+1 is committed only after epoch e, and at most one configuration is committed
\* (decided) for any epoch
C3_1 == \A i \in 1..Len(commits) :
          /\ \A j \in 1..Len(commits) : j # i => commits[j].rec.ep # commits[i].rec.ep
          /\ commits[i].rec.ep >= 1
          /\ commits[i].rec.ep = 1 \/ \E j \in 1..(i - 1) : commits[j].rec.ep = commits[i].rec.ep - 1

\* derives: C3.7, C3.8, F3.3 -- the nodes of a set of [node, incarnation] agreements; an agreement is
\* eligible in configuration X given the re-admissions R
NodesOf(S) == {a[1] : a \in S}
EligAg(a, X, R) == a[1] \in X.mem /\ (a[2] = 0 \/ a \in R)

\* derives: C3.7 -- every grant is issued under its decider's current configuration, records that
\* epoch, names the committed configuration of that epoch (not only what the decider believed), and
\* is counted by eligible agreements, one per node, from a majority of it
C3_7 == \A i \in 1..Len(grants) :
          LET g == grants[i]
              X == GCfgAt(g.ep) IN
          /\ g.ep = g.cep
          /\ X # NoConf
          /\ g.mem = X.mem
          /\ Cardinality(NodesOf(g.ag)) = Cardinality(g.ag)
          /\ \A a \in g.ag : EligAg(a, X, GRdm(g.ep, 0))
          /\ MajOf(NodesOf(g.ag), X.mem)

\* derives: C3.8 -- every decided commit of e+1 is counted by eligible agreements from a majority of the
\* committed configuration of e and from a majority of its own members (eligibility by re-admissions
\* other than this commit's), and its members are exactly its request's; an operator is told
\* success only for a request a commit names, at that commit's epoch, and only after it
C3_8 == /\ \A i \in 1..Len(commits) :
             LET c == commits[i]
                 Old == GCfgAt(c.rec.ep - 1) IN
             /\ Old # NoConf
             /\ \A a \in c.ago : EligAg(a, Old, GRdm(c.rec.ep - 1, i))
             /\ \A a \in c.agn : EligAg(a, c.rec, GRdm(c.rec.ep, i))
             /\ MajOf(NodesOf(c.ago), Old.mem)
             /\ MajOf(NodesOf(c.agn), c.rec.mem)
             /\ c.rec.rid \in DOMAIN ReqSets /\ c.rec.mem = ReqSets[c.rec.rid]
        /\ \A t \in opTold : t.outcome = "committed" =>
             \E i \in 1..Len(commits) : commits[i].rec.rid = t.rid /\ commits[i].rec.ep = t.ep

\* derives: C3.4, C3.5 -- the refusal rule, from a refusal's recorded inputs (contract v3 C3.4: invalid,
\* then busy; superseded when the commit is an input)
RefuseRule(f) == IF f.mem = {} \/ ~(f.mem \subseteq Nodes) THEN "invalid"
                 ELSE IF f.pin # "none" THEN "busy"
                 ELSE IF f.cin >= 0 THEN "superseded" ELSE "none"
\* derives: C3.5 -- every recorded decision's outcome is the model's fixed rule applied to the inputs
\* recorded with it, so two decisions of a kind with equal recorded inputs have equal outcomes (in
\* any two runs). Grants: token = last_token + 1 (client and epoch are inputs). Storage: accept or
\* serve iff token >= ledger; a served read returns stored_value. Decided commits: epoch =
\* old_epoch + 1, members = requested_members, readmits = the recorded agreements of incarnations
\* above 0 in the new membership. Refusals: RefuseRule.
C3_5 == /\ \A i \in 1..Len(grants) : grants[i].token = grants[i].lt + 1
        /\ \A i \in 1..Len(decisions) :
             (decisions[i].outcome = "accept") = (decisions[i].token >= decisions[i].hb)
        /\ \A i \in 1..Len(rdecisions) :
             /\ (rdecisions[i].outcome = "served") = (rdecisions[i].token >= rdecisions[i].hb)
             /\ rdecisions[i].outcome = "served" => rdecisions[i].value = rdecisions[i].held
        /\ \A i \in 1..Len(commits) :
             LET c == commits[i] IN
             /\ c.rec.ep = c.oep + 1
             /\ c.rec.mem = c.req
             /\ c.rec.rdm = {a \in c.ago \cup c.agn \cup c.agr : a[2] > 0 /\ a[1] \in c.req}
        /\ \A i \in 1..Len(refusals) : refusals[i].reason = RefuseRule(refusals[i])

\* derives: C3.4, F3.1 -- no reconfiguration request is pending at a lease node that is up
NoPending == \A x \in Nodes : up[x] => pend[x] = NoPend

\* derives: C1.4, F2.1, F2.2, C3.7, F3.1, F3.3; format v4 L3, v5 L3 -- C1.4's premise, read literally with
\* "connected" as failure model v2 defines it (direct, both directions): a majority Q of lease nodes and
\* storage are up and connected to each other, and connected to client c, which is up and
\* not paused. Q need not contain the grantor. Under v1 bipartitions this is the old Good(c).
\* X3 (contract v3 "C1.4 under v3"): the majority is of eligible members of the globally committed
\* configuration, more than half of whose members are eligible, and no request is pending at an up
\* lease node. "After the last fault" is the <>[] of C1_4.
Good(c) == /\ up[Store] /\ up[c] /\ ~paused[c]
           /\ Conn(c, Store)
           /\ NoPending
           /\ MajOf({q \in Nodes : GElig(q)}, GLatest.mem)
           /\ \E Q \in SUBSET {q \in Nodes : GElig(q)} :
                /\ MajOf(Q, GLatest.mem)
                /\ \A q \in Q : up[q] /\ Conn(q, Store) /\ Conn(q, c)
                /\ \A q, r \in Q : Conn(q, r)

\* derives: C1.4 -- if the good condition eventually holds forever, every pending
\* requester eventually stops waiting (obtains a grant)
C1_4 == \A c \in Clients : (<>[]Good(c)) => [](pending[c] => <>(~pending[c]))

\* derives: C3.4, F3.1, F3.3; format v5 L3 -- C3.4(b)'s premise for the request pending at x: x is up;
\* more than half of the globally committed configuration's members are eligible; and x, an eligible
\* majority of that configuration and an eligible majority of the requested set are up and connected
\* to each other
\* (C stands for the union of the two majorities: an up set, connected to each other and to x, holding an
\* eligible majority of each; one enumeration instead of one per pair of majorities)
GoodR(x) == pend[x] # NoPend =>
              /\ up[x]
              /\ MajOf({q \in Nodes : GElig(q)}, GLatest.mem)
              /\ \E C \in SUBSET {q \in Nodes : up[q] /\ Conn(q, x)} :
                   /\ MajOf({q \in C : GElig(q)}, GLatest.mem)
                   /\ MajOf({q \in C : EligIn(q, pend[x].mem, GRdm(GLatest.ep, 0))}, pend[x].mem)
                   /\ \A p, q \in C : Conn(p, q)
\* derives: C3.4 -- an outcome x owes operator o, or has sent it and o has not yet received it
Owes(x, o) == (\E a \in owed[x] : a.op = o) \/ (\E a \in opMsgs : a.op = o /\ a.x = x)
\* derives: C3.4 -- (b): a request pending at x under the premise is eventually committed or refused
\* superseded (its pending ends; this model ends it no other way, amnesia aside); and every
\* duty to tell: if x stays up and connected to o, o is eventually told what x owes it.
\* (a)'s `invalid`/`busy` refusals are recorded in the step that records the request.
C3_4 == /\ \A x \in Receivers : (<>[]GoodR(x)) => [](pend[x] # NoPend => <>(pend[x] = NoPend))
        /\ \A x \in Receivers, o \in Ops :
             (<>[](up[x] /\ Conn(x, o))) => [](Owes(x, o) => <>~Owes(x, o))

\* derives: C1.4, C3.4 (README X3 "Liveness, checked at terminal states") -- the state graph of this model
\* has no cycle but stuttering (Progress, checked on every run). Then every behaviour that satisfies
\* Fairness ends stuttering in a state where no fair step (FairNext) is enabled, and every path to
\* such a state, stuttering there, satisfies Fairness; so C1_4 and C3_4 hold iff at every such
\* reachable state each premise implies its conclusion. These invariants say that; ENABLED is
\* evaluated only where a premise holds and its conclusion does not.
C1_4T == (\E c \in Clients : Good(c) /\ pending[c]) => ENABLED <<FairNext>>_vars
\* derives: C3.4
C3_4T == (\/ \E x \in Receivers : GoodR(x) /\ pend[x] # NoPend
          \/ \E x \in Receivers, o \in Ops : up[x] /\ Conn(x, o) /\ Owes(x, o)) => ENABLED <<FairNext>>_vars
\* derives: C1.4, C3.4 (README X3 "Liveness, checked at terminal states") -- a progress measure: every
\* step but stuttering strictly increases it, lexicographically, so the state graph has no cycle but
\* stuttering. The components, in order: the schedule position; each node's promise (Elect, Join,
\* StepDown raise promises and no protocol step lowers one); the number of non-leaders (CheckQuorum);
\* grants; each client's request phase (waiting with no reply in flight < waiting with one < answered
\* with one in flight < answered); storage write and read decisions; commits; each node's recorded
\* configurations; and, decreasing, the acks queued and in flight, the read acks queued and in flight,
\* the requests in flight, and each node's replies owed. Per-node and per-client values are separate
\* components (none of them falls in a protocol step), which keeps the measure cheap to compute.
\* derives: C1.4
Phase(c) == LET inflight == \E m \in grantMsgs : m.c = c IN
            IF pending[c] THEN (IF inflight THEN 1 ELSE 0) ELSE (IF inflight THEN 2 ELSE 3)
\* derives: C1.4, C3.4 -- f applied along the sequence S
Along(S, f(_)) == [i \in 1..Len(S) |-> f(S[i])]
\* derives: C1.4, C3.4
Measure == <<pc>> \o Along(NodeSeq, LAMBDA n : promised[n])
           \o <<Cardinality({n \in Nodes : ~leader[n]}), Len(grants)>>
           \o Along(ClientSeq, Phase)
           \o <<Len(decisions), Len(rdecisions), Len(commits)>>
           \o Along(NodeSeq, LAMBDA n : Len(cfg[n]))
           \o <<-(2 * Cardinality(toAck) + Cardinality(ackMsgs)), -(2 * Cardinality(rToAck) + Cardinality(rAckMsgs)),
               -Cardinality(rcMsgs)>>
           \o Along(NodeSeq, LAMBDA n : -Cardinality(owed[n]))
\* derives: C1.4, C3.4 -- lexicographic order on equal-length tuples of integers
LexGt(a, b) == \E i \in 1..Len(a) : a[i] > b[i] /\ \A j \in 1..(i - 1) : a[j] = b[j]
\* derives: C1.4, C3.4 -- checked on every transition of every run (an action property, no liveness search)
\* (every step of Spec is a Next step or stutters, so "Next =>" is not written: evaluating Next as a
\* predicate on each transition cost ten times the search; the measures are bound by a quantifier,
\* which TLC evaluates once, where a LET was re-evaluated at each use)
Progress == [][\E after \in {Measure'}, before \in {Measure} : LexGt(after, before)]_vars

\* derives: C1.4, C3.4 -- the spec without fairness, for the acyclicity check (a cross-check of Progress)
SpecNF == Init /\ [][Next]_vars
\* derives: C1.4, C3.4 -- every behaviour eventually stops changing the fingerprinted state, i.e. the
\* state graph has no cycle other than stuttering (a violation is a lasso through a real cycle)
Acyclic == <>[][UNCHANGED View]_View

\* derives: C1.1, C1.4 -- bound check: no election ever reaches the last allowed term,
\* so MaxTerm never constrains a behaviour (run.sh reports a violation as UNEXPLAINED)
TermHeadroom == \A n \in Nodes : promised[n] < MaxTerm

\* derives: F1.1, F1.2, F1.3 -- witness target: the run ended and the system is quiescent
\* derives: F1.1, F1.2, F1.3; format v2 E1 -- quiescent: no request, write or ack in flight
\* and no client waiting for a grant, with crashed and paused processes not counted
\* (a message counts as in flight when its receiver is running)
Active(c) == up[c] /\ ~paused[c]
\* derives: F1.1, F1.2, F1.3, C3.4; format v2 E1, v5 E1
Quiescent == /\ \A m \in grantMsgs : ~Active(m.c)
             /\ writeMsgs = {} \/ ~up[Store]
             /\ \A a \in ackMsgs : ~Active(a.c)
             /\ \A a \in toAck : ~up[Store] \/ ~Active(a.c)
             /\ \A c \in Clients : Active(c) => ~pending[c]
             /\ readMsgs = {} \/ ~up[Store]                      \* derives: C2.1; format v2 E1
             /\ \A a \in rAckMsgs : ~Active(a.c)                  \* derives: C2.2; format v2 E1
             /\ \A a \in rToAck : ~up[Store] \/ ~Active(a.c)      \* derives: C2.2; format v2 E1
             /\ \A m \in rcMsgs : ~up[m.to]                       \* derives: C3.4; format v5 E1
             /\ NoPending                                         \* derives: C3.4; format v5 E1
             /\ \A x \in Nodes : up[x] => \A a \in owed[x] : ~Link(x, a.op)   \* derives: C3.4; v5 E1
             /\ opMsgs = {}                                       \* derives: C3.4; format v5 E1
\* derives: F1.1, F1.2, F1.3; format v2 E1 -- the run has reached its end: every step applied,
\* and either the end trigger fired (armed when the last step was taken) or, for
\* `end: quiescent`, the state is quiescent
Done == /\ pc = Len(Steps) + 1
        /\ IF EndTrig.event = "quiescent" THEN Quiescent ELSE fired
\* derives: F1.1, F1.2, F1.3 -- violated by any trace that reaches the end of the schedule
NotEnded == ~(Done /\ Quiescent)
\* derives: F1.1, F1.2, F1.3 -- weaker witness: the schedule's end trigger fired
NotDone == ~Done

def tla(v):
    # derives: F1.1, F1.2, F1.3 -- render a YAML scalar/collection as a TLA+ value
    if isinstance(v, bool):
        return "TRUE" if v else "FALSE"
    if isinstance(v, int):
        return str(v)
    if isinstance(v, str):
        return '"' + v.replace('"', '\\"') + '"'
    if isinstance(v, (set, frozenset)):
        return "{" + ", ".join(sorted(tla(x) for x in v)) + "}"
    if isinstance(v, list):
        return "<<" + ", ".join(tla(x) for x in v) + ">>"
    if isinstance(v, dict):
        return "[" + ", ".join(f"{k} |-> {tla(x)}" for k, x in v.items()) + "]"
    raise ScheduleError(f"cannot render {v!r}")


def trigger(t, procs):
    # derives: F1.1, F1.2, F1.3, F3.x -- a trigger is `start` or {event: E, field: value, ...}
    if t == "start":
        return {"event": "start"}
    if not isinstance(t, dict) or "event" not in t:
        raise ScheduleError(f"bad trigger {t!r}")
    ev = t["event"]
    if ev not in EVENTS or ev == "start":
        raise ScheduleError(f"trigger names unknown event {ev!r}")
    out = {"event": ev}
    for k, v in t.items():
        if k == "event":
            continue
        if k not in EVENT_FIELDS[ev]:
            raise ScheduleError(f"event {ev} has no field {k!r} the model can filter on")
        if k == "client" and v not in procs["clients"]:
            raise ScheduleError(f"unknown client {v!r}")
        if k == "outcome" and v not in OUTCOMES[ev]:
            raise ScheduleError(f"{ev} outcome must be one of {OUTCOMES[ev]}, got {v!r}")
        if k == "reason" and v not in REASONS:
            raise ScheduleError(f"reason must be one of {REASONS}, got {v!r}")
        if k == "members":
            # derives: C3.8 -- members compared as a set
            if not isinstance(v, list):
                raise ScheduleError("members filter must be a list")
            out[k] = set(map(str, v))
            continue
        if ev == "Fault" and k in ("crash", "restart", "pause", "resume", "clock"):
            # the model's Fault record names the action and its target
            out["action"], out["target"] = k, v
            continue
        out[k] = v
    return out


def proc_name(x, procs, allowed, aliases=("grantor", "holder")):
    # derives: F1.1, F1.2, F1.3; format v2 A1 -- a process name, or an alias where one may stand
    if x in aliases or x in allowed:
        return x
    raise ScheduleError(f"unknown or ill-typed process {x!r}")


def all_procs(procs):
    # derives: F1.2, F3.1 -- every process, operators included (format v5 "Processes")
    return set(procs["lease"]) | set(procs["clients"]) | set(procs["storage"]) | set(procs["operators"])


def action(d, procs, lifetime):
    # derives: C1.2, C1.4, F1.1, F1.2, F1.3, F3.x -- one step's action; rejects anything not in the model
    if not isinstance(d, dict):
        raise ScheduleError(f"bad action {d!r}")
    allp = all_procs(procs)
    lease = set(procs["lease"])
    clients = set(procs["clients"])
    if "cell" in d:
        cell = d["cell"]
        if cell not in FAULTS:
            raise ScheduleError(f"cell {cell!r} is not in failure-model/v3.md")
        keys = set(d) - {"cell"}
        verbs = keys & FAULTS[cell]
        if len(verbs) != 1:
            raise ScheduleError(f"fault step must name exactly one action of cell {cell}: {d!r}")
        (verb,) = verbs
        extra = keys - {verb}
        allowed_extra = V5_KEYS.get(verb, set()) if cell.startswith("F3") else set()
        if extra - allowed_extra:
            raise ScheduleError(f"unexpected keys {sorted(extra - allowed_extra)} in {d!r}")
        arg = d[verb]
        if cell == "F3.1":
            # derives: F3.1; format v5 R1 -- members are names (possibly not lease nodes: `invalid`);
            # `to` is a lease node or grantor, non-grantor, non-member
            if not isinstance(arg, list):
                raise ScheduleError("reconfigure needs a list of members")
            if "to" not in d or "id" not in d:
                raise ScheduleError("reconfigure needs `to` and `id`")
            to = d["to"]
            if to not in lease and to not in ("grantor", "non-grantor", "non-member"):
                raise ScheduleError(f"R1: `to` must be a lease node or grantor/non-grantor/non-member, got {to!r}")
            op = d.get("operator", "op")
            if op not in procs["operators"]:
                raise ScheduleError(f"unknown operator {op!r}")
            for x in arg:
                if x in ALIASES:
                    raise ScheduleError("R1: members are process names, not selectors")
            return {"kind": "reconfig", "p": to, "mem": set(map(str, arg)), "rid": str(d["id"]), "op": op}
        if cell == "F3.2":
            # derives: F3.2; format v5 R2 -- step x L must be a whole number of ticks
            step = d.get("step")
            if not isinstance(step, (int, float)) or isinstance(step, bool):
                raise ScheduleError("clock needs a numeric `step`")
            ticks = Fraction(str(step)) * lifetime
            if ticks.denominator != 1:
                raise ScheduleError(f"R2: step {step} x lifetime {lifetime} is not a whole number of ticks")
            return {"kind": "clock", "p": proc_name(arg, procs, allp, ("grantor", "holder", "non-grantor")),
                    "s": int(ticks), "step": step}
        if cell == "F3.3":
            # derives: F3.3; format v5 R3 -- only `restart: <lease node>, amnesia: true`
            if d.get("amnesia") is not True:
                raise ScheduleError("F3.3 restart needs `amnesia: true`")
            p = proc_name(arg, procs, lease, ("grantor", "non-grantor"))
            return {"kind": "amnesia", "p": p}
        if verb in ("crash", "restart"):
            # derives: F1.1; format v2.1 A1 -- non-grantor is a lease-node selector
            p = proc_name(arg, procs, allp, ("grantor", "holder", "non-grantor"))
            if p in procs["operators"]:
                raise ScheduleError("an operator does not crash (contract v3)")
            return {"kind": verb, "p": p}
        if verb in ("pause", "resume"):
            if arg == "grantor" or arg in lease | set(procs["storage"]) | set(procs["operators"]):
                raise ScheduleError("A2: only clients can be paused or resumed")
            return {"kind": verb, "p": proc_name(arg, procs, clients, ("holder",))}
        if verb == "heal":
            if arg is not True:
                raise ScheduleError("heal must be `heal: true`")
            # derives: F1.2, F2.1, F2.2; format v4 L2 -- every heal restores every link; the cell
            # it names is kept only for the Fault record
            return {"kind": "heal", "cell": cell}
        if verb in ("cut", "drop"):
            # derives: F2.1 (cut), F2.2 (drop); format v4 L1 -- a list of pairs of process names or
            # the selectors grantor, holder, non-grantor; `rest` is not allowed in a link
            if not (isinstance(arg, list) and arg):
                raise ScheduleError(f"{verb} needs a non-empty list of pairs")
            pairs = []
            for e in arg:
                if not (isinstance(e, list) and len(e) == 2):
                    raise ScheduleError(f"L1: each {verb} entry is a pair, got {e!r}")
                for x in e:
                    if x == "rest":
                        raise ScheduleError("L1: `rest` is not allowed in a link")
                    proc_name(x, procs, allp, ("grantor", "holder", "non-grantor"))
                pairs.append((e[0], e[1]))
            return {"kind": verb, "l": pairs, "cell": cell}
        if verb == "partition":
            if not (isinstance(arg, list) and len(arg) == 2):
                raise ScheduleError("partition needs exactly two sides (complete bipartition)")
            sides = []
            for side in arg:
                if not isinstance(side, list) or not side:
                    raise ScheduleError(f"bad partition side {side!r}")
                for x in side:
                    if x != "rest":
                        proc_name(x, procs, allp, ("grantor", "holder", "non-grantor"))
                sides.append(set(side))
            if "rest" in sides[0] and "rest" in sides[1]:
                raise ScheduleError("`rest` may appear on one side only")
            if "rest" not in sides[0] | sides[1]:
                named = {x for x in sides[0] | sides[1] if x not in ALIASES}
                if not (ALIASES & (sides[0] | sides[1])) and named != allp:
                    raise ScheduleError("partition without `rest` must name every process")
            return {"kind": "partition", "a": sides[0], "b": sides[1]}
    if set(d) - {"request", "write", "read", "value", "token"}:
        raise ScheduleError(f"action not in the schedule format: {d!r}")
    if "request" in d:
        if set(d) != {"request"}:
            raise ScheduleError(f"bad request {d!r}")
        return {"kind": "request", "p": proc_name(d["request"], procs, clients, ("holder",))}
    if "read" in d:
        # derives: C2.1, C2.2; format v3 -- read with the current or a stale token
        if set(d) - {"read", "token"}:
            raise ScheduleError(f"bad read {d!r}")
        tokspec = d.get("token")
        if tokspec not in (None, "stale"):
            raise ScheduleError(f"read token must be omitted or `stale`, got {tokspec!r}")
        return {"kind": "read", "p": proc_name(d["read"], procs, clients, ("holder",)),
                "stale": tokspec == "stale"}
    if "write" in d:
        if "value" not in d:
            raise ScheduleError("write needs a value")
        tokspec = d.get("token")
        if tokspec not in (None, "stale"):
            raise ScheduleError(f"write token must be omitted or `stale`, got {tokspec!r}")
        return {"kind": "write", "p": proc_name(d["write"], procs, clients, ("holder",)),
                "v": str(d["value"]), "stale": tokspec == "stale"}
    raise ScheduleError(f"unknown action {d!r}")


def static_checks(steps, procs):
    # derives: F1.1, F1.3, F3.1, F3.3; format v2 A1, A2, v5 R1, R3 -- reject what can be decided without running:
    # an alias used before any Grant can have occurred (no earlier request step), and
    # crash/restart/pause/resume of a process in the wrong state. An alias target is
    # tracked as "maybe" for every process it could denote; the model's own guards make
    # a step that is illegal at run time wait rather than act.
    lease, clients = set(procs["lease"]), set(procs["clients"])
    down, maybe_down = set(), set()          # crashed for sure / possibly crashed
    paused, maybe_paused = set(), set()
    requested = False
    ng_down = False
    ids = set()
    for i, (a, _) in enumerate(steps, 1):
        names = {a.get("p")} | set(a.get("a", ())) | set(a.get("b", ())) \
            | {x for e in a.get("l", ()) for x in e}   # derives: F2.1, F2.2; format v4 L1 (A1 applies)
        if names & {"grantor", "holder", "non-grantor"} and not requested:
            raise ScheduleError(f"A1: step {i} uses grantor/holder/non-grantor before any Grant can have occurred")
        k, p = a["kind"], a.get("p")
        if k == "reconfig":
            # derives: F3.1; format v5 R1 -- request ids are unique within the schedule
            if a["rid"] in ids:
                raise ScheduleError(f"R1: request id {a['rid']} used twice")
            ids.add(a["rid"])
            continue
        if k == "clock":
            continue
        if k == "amnesia":
            k = "restart"   # derives: F3.3; format v5 R3 -- an amnesic restart is a restart of a crashed lease node
        # derives: F1.1; format v2.2 A1 (restart: non-grantor is the node the most recent
        # crash: non-grantor crashed; rejected without an earlier one), v2.1 A1, v2 A2 -- restart: non-grantor needs an earlier,
        # not yet restarted, crash: non-grantor; crash: non-grantor is always of an up node
        if p == "non-grantor":
            if k == "crash":
                ng_down = True
                maybe_down |= lease
            elif k == "restart":
                if not ng_down:
                    raise ScheduleError(f"A2: step {i} restarts non-grantor, but no crash: non-grantor is outstanding")
                ng_down = False
            continue
        if k == "request":
            requested = True
        if k in ("crash", "restart"):
            cands = lease if p == "grantor" else clients if p == "holder" else {p}
            if k == "crash":
                if len(cands) == 1 and cands <= down:
                    raise ScheduleError(f"A2: step {i} crashes {p}, already crashed")
                if len(cands) == 1:
                    down |= cands
                    if p in clients:
                        paused.discard(p)
                        maybe_paused.discard(p)
                else:
                    maybe_down |= cands
            else:
                if not (cands & (down | maybe_down)):
                    raise ScheduleError(f"A2: step {i} restarts {p}, which is not crashed")
                if len(cands) == 1:
                    down -= cands
                    maybe_down -= cands
        if k in ("pause", "resume"):
            cands = clients if p == "holder" else {p}
            if k == "pause":
                if len(cands) == 1 and cands <= paused:
                    raise ScheduleError(f"A2: step {i} pauses {p}, already paused")
                if len(cands) == 1:
                    paused |= cands
                else:
                    maybe_paused |= cands
            else:
                if not (cands & (paused | maybe_paused)):
                    raise ScheduleError(f"A2: step {i} resumes {p}, which is running")
                if len(cands) == 1:
                    paused -= cands
                    maybe_paused -= cands
    return True


def tla_step(st, trig):
    # derives: F1.1, F1.2, F1.3, F2.1, F2.2, F3.x -- every step record gets the same fields (TLC compares
    # them); `l` is the link list of a cut/drop (a set of <<x, y>> pairs), `cell` names the heal's cell;
    # X3: `mem`, `rid`, `op` for a reconfigure, `s` (ticks) for a clock step
    rec = {"kind": st["kind"], "p": st.get("p", "none"), "v": st.get("v", "none"),
           "stale": st.get("stale", False), "a": set(st.get("a", set())),
           "b": set(st.get("b", set())), "trig": trig, "cell": st.get("cell", "none"),
           "mem": set(st.get("mem", set())), "rid": st.get("rid", "none"), "op": st.get("op", "none"),
           "s": st.get("s", 0)}
    links = "{" + ", ".join(sorted(f"<<{tla(x)}, {tla(y)}>>" for x, y in st.get("l", ()))) + "}"
    return tla(rec)[:-1] + f", l |-> {links}]"


def reach_probes(steps, procs):
    # derives: C3.1, C3.4, C3.7, C3.8, F3.1, F3.2, F3.3 (reach) -- what each schedule needs the model to reach:
    # every epoch its requests could commit, a grant under a changed configuration, each refusal reason a
    # request could get, re-admission where an amnesic node may agree to a commit listing it, an amnesic
    # incarnation, a timer fired early by a forward clock step, and the number of grants it requests
    kinds = [a["kind"] for a, _ in steps]
    reqs = [a for a, _ in steps if a["kind"] == "reconfig"]
    out = []
    nvalid = sum(1 for a in reqs if a["mem"] and a["mem"] <= set(procs["lease"]))
    for k in range(1, nvalid + 1):   # an invalid request never commits
        out.append((f"epoch{k}", f"\\E i \\in 1..Len(commits) : commits[i].rec.ep = {k}", f"epoch {k} committed"))
    if reqs and "request" in kinds[kinds.index("reconfig"):]:
        out.append(("grantNewEpoch", "\\E i \\in 1..Len(grants) : grants[i].ep >= 1", "a grant under epoch 1 or later"))
    valid = [a for a in reqs if a["mem"] and a["mem"] <= set(procs["lease"])]
    sel = {"grantor", "non-grantor", "non-member"}
    # two valid requests can meet at one receiver unless they name different nodes, or one goes to
    # `grantor` and the other to `non-grantor`
    same = any(a["p"] == b["p"] or ((a["p"] in sel or b["p"] in sel) and {a["p"], b["p"]} != {"grantor", "non-grantor"})
               for i, a in enumerate(valid) for b in valid[i + 1:])
    need = {"invalid": len(valid) < len(reqs), "busy": len(reqs) >= 2 and same, "superseded": len(valid) >= 2}
    for reason in ("invalid", "busy", "superseded"):
        if need[reason]:
            out.append((f"refused_{reason}", f'\\E i \\in 1..Len(refusals) : refusals[i].reason = "{reason}"',
                        f"a request refused as {reason}"))
    if "amnesia" in kinds:
        out.append(("amnesic", "\\E n \\in Nodes : inc[n] > 0", "an amnesic incarnation"))
        # re-admission is needed only where a request after an amnesic restart names the restarted node
        later = [(a, b) for i, (a, _) in enumerate(steps) if a["kind"] == "amnesia"
                 for b, _ in steps[i + 1:] if b["kind"] == "reconfig"]
        if any(a["p"] in b["mem"] or a["p"] in ("grantor", "non-grantor") for a, b in later):
            out.append(("readmit", "\\E i \\in 1..Len(commits) : commits[i].rec.rdm # {}", "a commit that re-admits"))
        if reqs:
            out.append(("readmitNot", "\\E i \\in 1..Len(commits) : commits[i].rec.rdm = {} /\\ \\E n \\in Nodes : inc[n] > 0",
                        "a commit after an amnesic restart that re-admits nobody"))
    if any(a["kind"] == "clock" and a["s"] > 0 for a, _ in steps):
        out.append(("early", "\\E n \\in Nodes : early[n]", "a lease node's timer fired early by a forward clock step"))
    if any(a["kind"] == "clock" for a, _ in steps):
        out.append(("clockStepped", "\\E p \\in DOMAIN off : off[p] # 0", "a clock offset after a step"))
    n = kinds.count("request")
    if n:
        out.append((f"grants{n}", f"Len(grants) >= {n}", f"{n} grants (one per request step)"))
    return out


INVARIANTS = ["TypeOK", "C1_1", "C1_2", "C1_3", "C2_1", "C2_2", "C3_1", "C3_7", "C3_8", "C3_5",
              "TermUnique", "C1_1order", "TermHeadroom"]   # derives: every clause; README X3 "What is checked"


def compile_schedule(path, outdir, lease, only=None):
    # derives: F1.1, F1.2, F1.3, F2.1, F2.2, F3.1, F3.2, F3.3
    # only: a mutation run checks this clause alone (an invariant or a property), with TypeOK and
    # TermHeadroom (README X3, "Mutation runs check the pair's clause")
    doc = yaml.safe_load(Path(path).read_text())
    for k in ("schedule", "processes", "steps", "end"):
        if k not in doc:
            raise ScheduleError(f"missing `{k}`")
    procs = dict(doc["processes"])
    procs.setdefault("operators", ["op"])           # derives: F3.1; format v5 "Processes"
    procs.setdefault("config", list(procs.get("lease", [])))
    procs["clients"] = procs.get("clients", [])
    nl = len(procs.get("lease", []))
    if not (1 <= nl <= MAX_LEASE) or len(procs["clients"]) < 1 or len(procs.get("storage", [])) != 1:
        raise ScheduleError(f"model takes 1 to {MAX_LEASE} lease nodes, at least 1 client, exactly 1 storage")
    if not procs["config"] or not set(procs["config"]) <= set(procs["lease"]):
        raise ScheduleError("format v5: `config` must be a non-empty subset of `lease`")
    names = procs["lease"] + procs["clients"] + procs["storage"] + procs["operators"]
    if len(set(names)) != len(names) or set(names) & ALIASES:
        raise ScheduleError("process names must be distinct and not selectors")
    lifetime = doc.get("lifetime", 1)
    if not isinstance(lifetime, int) or isinstance(lifetime, bool) or lifetime < 1:
        raise ScheduleError("format v5: `lifetime` is a positive whole number of ticks")
    steps = []
    for i, s in enumerate(doc["steps"], 1):
        if set(s) != {"at", "do"}:
            raise ScheduleError(f"step {i}: needs exactly `at` and `do`")
        steps.append((action(s["do"], procs, lifetime), trigger(s["at"], procs)))
    # derives: format v2 E1 -- `quiescent` or an event trigger
    end = {"event": "quiescent"} if doc["end"] == "quiescent" else trigger(doc["end"], procs)
    static_checks(steps, procs)
    bound = int((doc.get("bound") or {}).get("events", 200))
    # derives: C1.1, C1.4, F2.1, F2.2, F3.1, F3.2, F3.3 -- cut, drop, reconfigure, clock and amnesic
    # restarts count as fault steps for the term bound (a removal or a forward clock step may force
    # an election); this bounds the state space only, and TermHeadroom checks it never binds
    nfault = sum(1 for a, _ in steps
                 if a["kind"] in ("crash", "partition", "restart", "heal", "cut", "drop",
                                  "reconfig", "clock", "amnesia"))
    max_term = 2 + 2 * nfault          # elections happen only when no reachable leader exists
    max_dups = 1
    reqsets = {a["rid"]: a["mem"] for a, _ in steps if a["kind"] == "reconfig"}
    receivers = set()
    for a, _ in steps:
        if a["kind"] == "reconfig":
            receivers |= {a["p"]} if a["p"] in procs["lease"] else set(procs["lease"])

    outdir = Path(outdir)
    outdir.mkdir(parents=True, exist_ok=True)
    shutil.copy(lease, outdir / "Lease.tla")
    reqsets_tla = ("[x \\in {} |-> {}]" if not reqsets else
                   " @@ ".join(f"({tla(k)} :> {tla(v)})" for k, v in reqsets.items()))
    lines = [
        "---- MODULE MC ----",
        f"\\* derives: {', '.join(map(str, doc.get('derives', [])))} -- compiled from {Path(path).name}",
        "EXTENDS Lease",
        "\\* derives: C1.1, C1.4, F3.1",
        f"MCNodes == {tla(set(procs['lease']))}",
        "\\* derives: C3.1, C3.7, F3.1; format v5 config",
        f"MCInit0 == {tla(set(procs['config']))}",
        "\\* derives: C1.2, C1.3, C1.4",
        f"MCClients == {tla(set(procs['clients']))}",
        "\\* derives: C1.2, C1.3",
        f"MCStore == {tla(procs['storage'][0])}",
        "\\* derives: C3.4, C3.8, F3.1; format v5 operators",
        f"MCOps == {tla(set(procs['operators']))}",
        "\\* derives: C3.8 -- request id -> requested set",
        f"MCReqSets == {reqsets_tla}",
        "\\* derives: C3.4",
        f"MCReceivers == {tla(receivers)}",
        "\\* derives: C1.4, C3.4 -- fixed orders for the progress measure",
        f"MCNodeSeq == {tla(sorted(procs['lease']))}",
        f"MCClientSeq == {tla(sorted(procs['clients']))}",
        "\\* derives: F1.1, F1.2, F1.3, F2.1, F2.2, F3.x",
        "MCSteps == <<",
        ",\n".join("    " + tla_step(a, t) for a, t in steps),
        ">>",
        "\\* derives: F1.1, F1.2, F1.3",
        f"MCEnd == {tla(end)}",
        "====",
    ]
    (outdir / "MC.tla").write_text("\n".join(lines) + "\n")
    consts = (
        "CONSTANTS\n"
        "  Nodes <- MCNodes\n  Init0 <- MCInit0\n  Clients <- MCClients\n  Store <- MCStore\n"
        "  Ops <- MCOps\n  ReqSets <- MCReqSets\n  Receivers <- MCReceivers\n"
        f'  Key = "k"\n  Lifetime = {lifetime}\n  Steps <- MCSteps\n  EndTrig <- MCEnd\n'
        f"  MaxTerm = {max_term}\n  MaxDups = {max_dups}\n  NodeSeq <- MCNodeSeq\n  ClientSeq <- MCClientSeq\n"
        "SPECIFICATION Spec\n"
        "VIEW View\n"   # derives: (bounds) -- README X3 "Bounds": lastEv is not fingerprinted
    )
    # derives: C1.4, C3.4 (README X3 "Liveness, checked at terminal states") -- the checking run checks every
    # clause invariant and the terminal-state forms of the liveness clauses; Acyclic.cfg checks, without
    # fairness, that the state graph has no cycle but stuttering, which makes those forms exact; Live.cfg
    # is TLC's own liveness check under the fairness of Spec, used only if a cycle is found
    props = ["C1_4"] + (["C3_4"] if reqsets else [])
    terms = [p + "T" for p in props]
    (outdir / "MC.cfg").write_text(
        "\\* derives: C1.1, C1.2, C1.3, C1.4, C2.1, C2.2, C3.1, C3.4, C3.5, C3.7, C3.8\n" + consts +
        "INVARIANT " + " ".join(INVARIANTS[:-2] + terms + INVARIANTS[-2:]) + "\n" + "PROPERTY Progress\n")
    (outdir / "Acyclic.cfg").write_text(
        "\\* derives: C1.4, C3.4\n" + consts.replace("SPECIFICATION Spec\n", "SPECIFICATION SpecNF\n") +
        "PROPERTY Acyclic\n")
    (outdir / "Live.cfg").write_text("\\* derives: C1.4, C3.4\n" + consts + "".join(f"PROPERTY {p}\n" for p in props))
    for p in props:
        (outdir / f"MC_{p}.cfg").write_text("\\* derives: C1.4, C3.4\n" + consts + f"PROPERTY {p}\n")
    if only is not None:
        inv = only + "T" if only in ("C1_4", "C3_4") else only
        (outdir / "MC_only.cfg").write_text(f"\\* derives: {only} (mutation run)\n" + consts +
                                            f"INVARIANT TypeOK {inv} TermHeadroom\n" +
                                            ("PROPERTY Progress\n" if only in ("C1_4", "C3_4") else ""))
    # derives: (reach; README X3 "Reach") -- probes: each RP_x is a state the schedule needs the model to be
    # able to reach; Reach_x.cfg checks ~RP_x, so a violation is a witness that x is reachable
    probes = reach_probes(steps, procs)
    mc = (outdir / "MC.tla").read_text().replace("====\n", "".join(
        f"\\* derives: (reach) -- {why}\nRP_{k} == {p}\nNRP_{k} == ~RP_{k}\n" for k, p, why in probes) + "====\n")
    (outdir / "MC.tla").write_text(mc)
    for k, _, _ in probes:
        (outdir / f"Reach_{k}.cfg").write_text("\\* derives: (reach)\n" + consts + f"INVARIANT NRP_{k}\n")
    (outdir / "Witness.cfg").write_text(
        "\\* derives: F1.1, F1.2, F1.3\n" + consts + "INVARIANT NotEnded\n")
    (outdir / "Done.cfg").write_text(
        "\\* derives: F1.1, F1.2, F1.3\n" + consts + "INVARIANT NotDone\n")
    meta = {"schedule": doc["schedule"], "derives": doc.get("derives", []),
            "processes": procs, "bound": bound, "max_term": max_term, "max_dups": max_dups,
            "lifetime": lifetime, "props": props, "probes": [[k, why] for k, _, why in probes],
            "steps": [{"do": s["do"], "at": s["at"]} for s in doc["steps"]], "end": doc["end"]}
    (outdir / "schedule.json").write_text(json.dumps(meta, indent=1, default=list))
    return meta


def main(argv):
    if len(argv) < 3:
        print(__doc__, file=sys.stderr)
        return 2
    lease = Path(__file__).with_name("Lease.tla")
    if "--lease" in argv:
        lease = Path(argv[argv.index("--lease") + 1])
    try:
        compile_schedule(argv[1], argv[2], lease)
    except ScheduleError as e:
        print(f"schedule rejected: {e}", file=sys.stderr)
        return 2
    return 0


if __name__ == "__main__":
    sys.exit(main(sys.argv))

(* The tupay lease service of contract/v3.md under failure-model/v3.md,   *)
(* driven by one compiled schedule (testbed/schedule-format.md, v5).        *)
(*                                                                         *)
(* Agreement and membership follow Raft with joint consensus (Ongaro and   *)
(* Ousterhout, USENIX ATC 2014, sections 5 and 6), with PreVote and        *)
(* CheckQuorum (Ongaro, PhD thesis, Stanford 2014, sections 9.6 and 6.2).  *)
(* An amnesic incarnation is a new, non-voting server until a membership   *)
(* change re-admits it (thesis 3.8 and 4.2.1). Adaptations to the contract *)
(* and every abstraction are listed in README.md; the main ones:           *)
(*  - a grant is decided by the leader that created its entry, from        *)
(*    acknowledgements in its own term (Raft's direct commitment);         *)
(*  - a configuration commit is decided by the request's receiver, a       *)
(*    distinguished learner (Lamport, Paxos Made Simple, 2001, 2.3), when  *)
(*    a leader that knows the joint entry committed hands it the agreements *)
(*    it counted, so each epoch has exactly one deciding node;             *)
(*  - C_new is implied: a node uses the new membership alone once it knows *)
(*    the epoch decided, and the joint one while the entry is undecided;   *)
(*  - messages between lease nodes are atomic steps (sent and received in  *)
(*    one step while the link is up), as in published atomic-quorum       *)
(*    abstractions of Raft; messages to and from clients, storage and      *)
(*    operators are explicit and may stay in flight;                       *)
(*  - no protocol decision reads a clock (expiry is not waited on), so a   *)
(*    clock step (F3.2) is recorded and changes no state.                  *)

(* Configurations, eligibility, majorities (contract v3 terms)             *)

\* derives: C3.1 -- a node's current configuration: the highest epoch it knows committed

\* derives: C3.1, C3.8

\* derives: C3.7, C3.8 -- members of epoch e as n knows them (decided, or from its log)
MemOf(n, e) == IF e \in DOMAIN cfgs[n] THEN cfgs[n][e].mem
               ELSE LET I == {i \in CfgIdx(n) : log[n][i].ep = e}

\* derives: C3.8, C1.4 -- the epochs whose majorities n's protocol needs (two while joint)
OpEps(n) == IF UndecIdx(n) = {} THEN {Cur(n)}
            ELSE LET J == log[n][SetMax(UndecIdx(n))] IN {J.ep - 1, J.ep}
\* derives: C3.8, C1.4

\* derives: F3.3, C3.7, C3.8 -- incarnations re-admitted by commits of epoch at most e that n knows
Readm(n, e) == UNION {cfgs[n][x].rm : x \in {y \in DOMAIN cfgs[n] : y <= e}}
\* derives: F3.3, C3.7, C3.8 -- "Eligible agreement", judged with n's knowledge
EligK(n, q, qi, e) == q \in MemOf(n, e) /\ (qi = 0 \/ <<q, qi>> \in Readm(n, e))
\* derives: C3.7, C3.8 -- "Majority of a configuration": eligible agreements from more than half of all members
MajK(n, P, e) == 2 * Cardinality({p[1] : p \in {x \in P : EligK(n, x[1], x[2], e)}}) > Cardinality(MemOf(n, e))
\* derives: C3.8, C1.1 -- every majority n's protocol needs
QuorumK(n, P) == \A e \in OpEps(n) : MajK(n, P, e)
\* derives: F3.3 -- n may campaign only as an eligible member (non-voting otherwise)
SelfOK(n) == \E e \in OpEps(n) : EligK(n, n, inc[n], e)
\* derives: C1.1 -- Raft's election restriction: log a at least as up to date as log b
LastTerm(lg) == IF lg = <<>> THEN 0 ELSE lg[Len(lg)].t
\* derives: C1.1

\* derives: C1.4 -- nodes a leader replicates to

\* derives: C1.4, F2.2 -- q hears a leader it would follow

\* derives: F1.1 -- Rule T1: an event matches a trigger's event name and field filters

\* derives: F1.1
Hit(t, evs) == t.kind = "ev" /\ \E j \in 1..Len(evs) : Matches(t, evs[j])

(* Leader-side evaluation after an acknowledgement or an append            *)
(***************************************************************************)
\* derives: C1.1 -- highest token among the grant entries before index i of log lg
LastTok(lg, i) == LET T == {lg[j].tok : j \in {j \in 1..(i - 1) : lg[j].k = "g"}}
                  IN IF T = {} THEN 0 ELSE SetMax(T)
\* derives: C1.1

\* derives: C1.1, C3.7 -- l has recorded the Grant for entry g

\* derives: C1.4 -- the reply to a decided grant: direct, and relayed by the node that forwarded the request

  LET m(fr) == [ty |-> "gm", c |-> g.c, rid |-> g.rid, tok |-> g.tok, gt |-> g.t, fr |-> fr]
  IN IF Link(l, g.c) \/ g.via = l THEN Send(l, m(l))
     ELSE IF alive[g.via] /\ Link(l, g.via) THEN Send(g.via, m(g.via)) ELSE {}
\* derives: C3.8 -- identity of a configuration entry, as handed to its receiver
JId(J) == [ep |-> J.ep, rid |-> J.rid, mem |-> J.mem, rcv |-> J.rcv, rinc |-> J.rinc]
\* derives: C1.1, C3.7, C3.8, C3.5 -- what leader l decides, given its log lg, match row M and recorded agreements A
Eval(l, lg, M, A) ==
  LET own == {i \in 1..Len(lg) : lg[i].k = "g" /\ lg[i].t = term[l] /\ ~Decided(l, lg[i])}
      Sg(i) == {<<x.q, x.qi>> : x \in {y \in A : y.i = i}}
      D == {i \in own : lg[i].ep = Cur(l) /\ MajK(l, Sg(i), lg[i].ep)}
      Ds == SortSet(D)
      EvG(i) == [event |-> "Grant", proc |-> l, client |-> lg[i].c, key |-> KeyName, token |-> lg[i].tok,
                 lifetime |-> Life, grantor_term |-> term[l], config_epoch |-> lg[i].ep, rid |-> lg[i].rid,

      Ack(i) == {<<q, M[q].inc>> : q \in {q \in Lease \ {l} : M[q].len >= i}} \cup {<<l, inc[l]>>}
      CIs == {i \in 1..Len(lg) : lg[i].t = term[l] /\ QuorumK(l, Ack(i))}
      CI == IF CIs = {} THEN 0 ELSE SetMax(CIs)
      cj == {j \in 1..CI : lg[j].k = "c" /\ lg[j].ep > Cur(l)}
  IN [ev |-> [k \in 1..Len(Ds) |-> EvG(Ds[k])],
      gr |-> {[tok |-> lg[i].tok, ep |-> lg[i].ep, term |-> term[l], d |-> l, di |-> inc[l],
               c |-> lg[i].c, rid |-> lg[i].rid] : i \in D},
      lg |-> IF D = {} THEN lastG ELSE [node |-> l, client |-> lg[SetMax(D)].c],
      msgs |-> UNION {GrantMsgs(l, lg[i]) : i \in D},
      atoms |-> UNION {{[j |-> JId(lg[j]), q |-> x[1], qi |-> x[2]] : x \in Ack(j)} : j \in cj}]
\* derives: C3.7 -- counted_toward of an agreement to a grant of epoch e
CT(l, q, qi, e) == IF EligK(l, q, qi, e) THEN {e} ELSE {}

  /\ pend = [n \in Lease |-> NoPend]
  /\ cq = [n \in Lease |-> {}]
  /\ rq = [n \in Lease |-> {}]

(***************************************************************************)
(* Elections: Raft with PreVote and CheckQuorum                            *)
(***************************************************************************)
\* derives: C1.1, C1.4 -- the TLC term bound: MaxTerm before the last fault; after it, room for one election per
\* lease node (elections after the last fault settle; reaching this cap means they did not, and is reported)
TermCap == IF pc > LastFault THEN MaxTerm + Len(LeaseSeq) ELSE MaxTerm
\* derives: C1.4, F3.3 -- n may start an election
CanCampaign(n) == alive[n] /\ role[n] # "L" /\ term[n] < TermCap /\ n \in OpMembers(n) /\ SelfOK(n)
\* derives: C1.4, F2.1, F2.2 -- PreVote: members that would grant a pre-vote (they hear no leader and the log is up to
\* date); a pre-vote rejected for a stale term teaches the higher term and is retried (as etcd does), so terms do
\* not gate it here
PV(n) == {<<q, inc[q]>> : q \in {q \in OpMembers(n) \cup {n} : alive[q] /\
            (q = n \/ (Conn(n, q) /\ ~HearsLeader(q) /\ UpToDate(log[n], log[q])))}}
\* derives: C1.1
BecomeCand(n) == /\ term' = [term EXCEPT ![n] = @ + 1]
                 /\ voted' = [voted EXCEPT ![n] = n]
                 /\ role' = [role EXCEPT ![n] = "C"]
\* derives: C1.1 -- peers that would vote for candidate n (term, votedFor and log checks)
Voters(n) == {q \in OpMembers(n) \cup {n} : alive[q] /\
               (q = n \/ (Conn(n, q) /\ (term[q] < term[n] \/ (term[q] = term[n] /\ voted[q] \in {"none", n}))
                          /\ UpToDate(log[n], log[q])))}
\* derives: C1.1, C1.4, C3.8 -- n wins term t with eligible votes Q from every majority it needs
WinEff(n, t, Q) ==
  /\ term' = [q \in Lease |-> IF q \in Q THEN t ELSE term[q]]
  /\ voted' = [q \in Lease |-> IF q \in Q THEN n ELSE voted[q]]
  /\ role' = [q \in Lease |-> IF q = n THEN "L" ELSE IF q \in Q THEN "F" ELSE role[q]]
  /\ log' = IF UndecIdx(n) # {} THEN [log EXCEPT ![n] = Append(@, [k |-> "n", t |-> t])] ELSE log
  /\ mi' = [mi EXCEPT ![n] = [m \in Lease |-> [inc |-> 0, len |-> 0]]]
  /\ agd' = [agd EXCEPT ![n] = {}]
  /\ ev' = <<>>
  /\ UNCHANGED <<histV, alive, inc, cfgs, pend, cq, rq, kb, rag, rep, cliV, stoV, net, down, opgot>>
\* derives: C1.4, F1.1, F1.2, F2.1, F2.2 -- an election that is needed (no leader heard, a pre-vote quorum),
\* taken in one step: the timeouts (repeated until a term at which a quorum would vote, the smallest such term),
\* the votes of every peer that would vote, the win
VotersAt(n, t) == {q \in OpMembers(n) \cup {n} : alive[q] /\
                    (q = n \/ (Conn(n, q) /\ (term[q] < t \/ (term[q] = t /\ voted[q] \in {"none", n}))
                               /\ UpToDate(log[n], log[q])))}
\* derives: C1.4, F1.1, F1.2, F2.1, F2.2
Elect(n) ==
  /\ CanCampaign(n) /\ ~HearsLeader(n) /\ QuorumK(n, PV(n))
  /\ LET Ts == {t \in (term[n] + 1)..TermCap : QuorumK(n, {<<q, inc[q]>> : q \in VotersAt(n, t)})}
         t == SetMin(Ts)
     IN /\ Ts # {}
        /\ WinEff(n, t, VotersAt(n, t))
  /\ UNCHANGED spur
\* derives: C1.1, F1.2, F2.1 -- asynchrony before the last fault (bounded by Spur0): a timeout while a leader is
\* still reachable; the node either wins at once (with every member that would vote, at the smallest such term) or
\* is left a candidate whose RequestVote raises its peers' terms (TermProp) until some leader's AppendEntries reaches it
SpurElect(n) ==
  /\ CanCampaign(n) /\ spur > 0 /\ pc <= LastFault /\ spur' = spur - 1
  /\ LET Ts == {t \in (term[n] + 1)..TermCap : QuorumK(n, {<<q, inc[q]>> : q \in VotersAt(n, t)})}
         t == SetMin(Ts)
     IN /\ Ts # {}
        /\ WinEff(n, t, VotersAt(n, t))
\* derives: C1.1, F1.2, F2.1
SpurFail(n) ==
  /\ CanCampaign(n) /\ spur > 0 /\ pc <= LastFault /\ spur' = spur - 1
  /\ BecomeCand(n) /\ ev' = <<>>
  /\ UNCHANGED <<histV, alive, inc, log, mi, cfgs, pend, cq, rq, kb, agd, rag, rep, cliV, stoV, net, down, opgot>>
\* derives: C1.4, F2.2 -- CheckQuorum: a leader that cannot hear a majority, or is no longer a member, steps down
Hear(l) == {<<q, inc[q]>> : q \in {q \in Lease : q = l \/ (alive[q] /\ Conn(l, q) /\ term[q] <= term[l])}}
\* derives: C1.4, F2.2, F3.1
StepDown(l) ==
  /\ role[l] = "L" /\ alive[l]
  /\ (~QuorumK(l, Hear(l)) \/ l \notin OpMembers(l))
  /\ role' = [role EXCEPT ![l] = "F"] /\ ev' = <<>>
  /\ UNCHANGED <<histV, alive, inc, term, voted, log, mi, cfgs, pend, cq, rq, kb, agd, rag, rep, spur,
                 cliV, stoV, net, down, opgot>>
\* derives: C1.1, C1.4 -- a higher term carried on a message (an AppendEntries reply, a RequestVote) deposes
TermProp(n, m) ==
  /\ n # m /\ alive[n] /\ alive[m] /\ term[n] > term[m] /\ Link(n, m)
  /\ \/ (role[m] = "L" /\ n \in AERcpt(m) /\ Link(m, n))
     \/ (role[n] = "C" /\ m \in OpMembers(n))
  /\ term' = [term EXCEPT ![m] = term[n]]
  /\ voted' = [voted EXCEPT ![m] = "none"]
  /\ role' = [role EXCEPT ![m] = "F"]
  /\ ev' = <<>>
  /\ UNCHANGED <<histV, alive, inc, log, mi, cfgs, pend, cq, rq, kb, agd, rag, rep, spur, cliV, stoV, net, down, opgot>>

(* Grant replies: to a running client in the step they are sent            *)
(***************************************************************************)
\* derives: C1.1, C1.4, F1.3 -- grant replies G sent now: a running client takes the one answering its request at
\* once; a reply to a paused client stays in flight until it resumes
GMApply(G, cr0) ==
  LET now == {m \in G : ~paused[m.c]}
      got(c) == {m \in now : m.c = c /\ cr0[c] = m.rid}
      pick(c) == CHOOSE m \in got(c) : \A m2 \in got(c) : m2.tok <= m.tok
  IN [later |-> G \ now,
      ctok |-> [c \in Clients |-> IF got(c) # {} THEN [tok |-> pick(c).tok, gt |-> pick(c).gt] ELSE ctok[c]],
      ctoks |-> [c \in Clients |-> IF got(c) # {} THEN ctoks[c] \cup {[tok |-> pick(c).tok, gt |-> pick(c).gt]}
                                   ELSE ctoks[c]],
      creq |-> [c \in Clients |-> IF got(c) # {} THEN 0 ELSE cr0[c]]]
\* derives: C1.1, C1.4
SendGMs(G, net0, cr0) ==
  LET R == GMApply(G, cr0)
  IN /\ net' = net0 \cup R.later
     /\ ctok' = R.ctok /\ ctoks' = R.ctoks /\ creq' = R.creq

(* Replication: AppendEntries and its acknowledgement, in one step         *)
(***************************************************************************)
\* derives: C1.1, C3.7, C3.8, F1.2, F2.1, F2.2 -- f takes l's log; f's acknowledgement reaches l iff f->l is up
AE(l, f) ==
  /\ role[l] = "L" /\ alive[l] /\ alive[f] /\ f \in AERcpt(l) /\ Link(l, f) /\ term[f] <= term[l]
  /\ LET L0 == log[l]
         newI == SelectSeq([i \in 1..Len(L0) |-> i],
                           LAMBDA i : L0[i].k # "n" /\ ~(i <= Len(log[f]) /\ log[f][i] = L0[i]))
         agrees == [k \in 1..Len(newI) |-> EvAgree(f, inc[f], Prop(L0[newI[k]]))]
         ack == Link(f, l)
         row == [mi[l] EXCEPT ![f] = [inc |-> inc[f], len |-> Len(L0)]]
         own == {i \in 1..Len(L0) : L0[i].k = "g" /\ L0[i].t = term[l] /\ ~Decided(l, L0[i])}
         newA == {[q |-> f, qi |-> inc[f], i |-> i] : i \in own} \ agd[l]
         newAs == SortSet({a.i : a \in newA})
         agreedEvs == [k \in 1..Len(newAs) |->
                         EvAgreed(l, f, inc[f], GProp(L0[newAs[k]]), CT(l, f, inc[f], L0[newAs[k]].ep))]
         A == agd[l] \cup newA
         E == Eval(l, L0, row, A)
     IN
     /\ (log[f] # L0 \/ term[f] # term[l] \/ role[f] # "F" \/ (ack /\ mi[l][f] # row[f]))
     /\ term' = [term EXCEPT ![f] = term[l]]
     /\ voted' = IF term[f] < term[l] THEN [voted EXCEPT ![f] = "none"] ELSE voted
     /\ role' = [role EXCEPT ![f] = "F"]
     /\ log' = [log EXCEPT ![f] = L0]
     /\ IF ack
        THEN /\ mi' = [mi EXCEPT ![l] = row]
             /\ agd' = [agd EXCEPT ![l] = A]
             /\ gr' = gr \cup E.gr
             /\ lastG' = E.lg
             /\ SendGMs(E.msgs, net, creq)
             /\ kb' = [kb EXCEPT ![l] = @ \cup E.atoms]
             /\ ev' = agrees \o agreedEvs \o E.ev
        ELSE /\ ev' = agrees
             /\ UNCHANGED <<mi, agd, gr, lastG, net, kb, ctok, ctoks, creq>>
  /\ UNCHANGED <<dc, acc, srv, rqs, hiw, alive, inc, cfgs, pend, cq, rq, rag, rep, spur, paused, stoV, down, opgot>>

(* Grant requests: arrival, forwarding, proposal                           *)
(***************************************************************************)
\* derives: C1.1, C3.7 -- l's own-term decided grant answering request x
OwnDec(n, r, x) == r.d = n /\ r.di = inc[n] /\ r.term = term[n] /\ r.c = x.c /\ r.rid = x.rid
\* derives: C1.1
OwnEntry(n, x) == \E i \in 1..Len(log[n]) : log[n][i].k = "g" /\ log[n][i].t = term[n]
                                              /\ log[n][i].c = x.c /\ log[n][i].rid = x.rid
\* derives: C1.1, C3.7 -- a leader proposes no grant while a membership change is undecided in its log
CanProposeG(n) == UndecIdx(n) = {}
\* derives: C1.1, C3.7 -- append a grant entry for request x; token: one above every token in l's log
Propose(l, x, rq0, net0, ev0, cr0) ==
  LET g == [k |-> "g", t |-> term[l], c |-> x.c, rid |-> x.rid, tok |-> MaxTok(log[l]) + 1,
            ep |-> Cur(l), via |-> x.via]
      LG == Append(log[l], g)
      A == agd[l] \cup {[q |-> l, qi |-> inc[l], i |-> Len(LG)]}
      E == Eval(l, LG, mi[l], A)
  IN /\ log' = [log EXCEPT ![l] = LG]
     /\ agd' = [agd EXCEPT ![l] = A]
     /\ rq' = rq0
     /\ SendGMs(E.msgs, net0, cr0)
     /\ gr' = gr \cup E.gr
     /\ lastG' = E.lg
     /\ kb' = [kb EXCEPT ![l] = @ \cup E.atoms]
     /\ ev' = ev0 \o <<EvAgree(l, inc[l], GProp(g)), EvAgreed(l, l, inc[l], GProp(g), CT(l, l, inc[l], g.ep))>>
              \o E.ev
     /\ UNCHANGED mi
\* derives: C1.1, C1.4 -- nothing more happens to request x
Hold(rq0, net0, ev0, cr0) == /\ net' = net0 /\ rq' = rq0 /\ ev' = ev0 /\ creq' = cr0
                             /\ UNCHANGED <<log, mi, agd, kb, gr, lastG, ctok, ctoks>>
\* derives: C1.1, C1.4 -- what leader n does with a grant request x
HandleL(n, x, rq0, net0, ev0, cr0) ==
  IF \E r \in gr : OwnDec(n, r, x)
  THEN LET r == CHOOSE r \in gr : OwnDec(n, r, x)
       IN /\ SendGMs(Send(n, [ty |-> "gm", c |-> r.c, rid |-> r.rid, tok |-> r.tok, gt |-> r.term, fr |-> n]),
                     net0, cr0)
          /\ rq' = rq0 /\ ev' = ev0
          /\ UNCHANGED <<log, mi, agd, kb, gr, lastG>>
  ELSE IF OwnEntry(n, x) THEN Hold(rq0, net0, ev0, cr0)
  ELSE IF CanProposeG(n) THEN Propose(n, x, rq0, net0, ev0, cr0)
  ELSE Hold([rq0 EXCEPT ![n] = @ \cup {x}], net0, ev0, cr0)
\* derives: C1.4, F2.1 -- leaders a non-leader n can pass a request to
Reach(n) == {l \in Lease : l # n /\ role[l] = "L" /\ alive[l] /\ Link(n, l)}
\* derives: C1.1, C1.4 -- what node n does with a grant request x: a non-leader passes it at once to a leader
\* it reaches (H9: the grantor need not reach the client), or holds it
Handle(n, x, rq0, net0, ev0, cr0) ==
  IF role[n] = "L" THEN HandleL(n, x, rq0, net0, ev0, cr0)
  ELSE IF Reach(n) # {} THEN \E l \in Reach(n) : HandleL(l, x, rq0, net0, ev0, cr0)
  ELSE Hold([rq0 EXCEPT ![n] = @ \cup {x}], net0, ev0, cr0)
\* derives: C1.4, F1.2, F2.1 -- client c sends request rid to every lease node, arriving in the step it is sent
\* where c->n is up: a leader it reaches takes it; else a node it reaches passes it to a leader that node reaches
\* (H9); else nobody takes it, and the client tries again (Retransmit) once a leader can be reached
Broadcast(c, rid, ev0, cr0) ==
  LET R == {n \in Lease : alive[n] /\ Link(c, n)}
      LR == {n \in R : role[n] = "L"}
      FR == {n \in R : Reach(n) # {}}
  IN IF LR # {} THEN \E l \in LR : HandleL(l, [c |-> c, rid |-> rid, via |-> l], rq, net, ev0, cr0)
     ELSE IF FR # {} THEN \E n \in FR : \E l \in Reach(n) : HandleL(l, [c |-> c, rid |-> rid, via |-> n], rq, net, ev0, cr0)
     ELSE Hold(rq, net, ev0, cr0)
\* derives: C1.4, F2.1 -- a non-leader passes a held request to a leader it can reach
Forward(n, l, x) ==
  /\ x \in rq[n] /\ n # l /\ role[n] # "L" /\ role[l] = "L" /\ alive[n] /\ alive[l] /\ Link(n, l)
  /\ HandleL(l, x, [rq EXCEPT ![n] = @ \ {x}], net, <<>>, creq)
  /\ UNCHANGED <<dc, acc, srv, rqs, hiw, alive, inc, term, voted, role, cfgs, pend, cq, rag, rep, spur,
                 paused, stoV, down, opgot>>
\* derives: C1.4 -- a leader proposes a request it holds once grants are no longer paused
ProposeQ(l, x) ==
  /\ x \in rq[l] /\ role[l] = "L" /\ alive[l]
  /\ (CanProposeG(l) \/ OwnEntry(l, x) \/ \E r \in gr : OwnDec(l, r, x))
  /\ HandleL(l, x, [rq EXCEPT ![l] = @ \ {x}], net, <<>>, creq)
  /\ UNCHANGED <<dc, acc, srv, rqs, hiw, alive, inc, term, voted, role, cfgs, pend, cq, rag, rep, spur,
                 paused, stoV, down, opgot>>
\* derives: C1.1, C1.4, F1.3 -- a paused client, resumed, takes a grant reply that waited for it
DeliverGM(m) ==
  /\ m \in net /\ m.ty = "gm" /\ alive[m.c] /\ ~paused[m.c]
  /\ net' = net \ {m}
  /\ IF creq[m.c] = m.rid
     THEN /\ ctok' = [ctok EXCEPT ![m.c] = [tok |-> m.tok, gt |-> m.gt]]
          /\ ctoks' = [ctoks EXCEPT ![m.c] = @ \cup {[tok |-> m.tok, gt |-> m.gt]}]
          /\ creq' = [creq EXCEPT ![m.c] = 0]
     ELSE UNCHANGED <<ctok, ctoks, creq>>
  /\ ev' = <<>>
  /\ UNCHANGED <<histV, alive, inc, term, voted, role, log, mi, cfgs, pend, cq, rq, kb, agd, rag, rep, spur,
                 paused, stoV, down, opgot>>
\* derives: C1.4 -- c's outstanding request is nowhere: not held, not in progress, no reply in flight
ReqLost(c) ==
  LET x == [c |-> c, rid |-> creq[c]] IN
  /\ ~\E m \in net : m.ty = "gm" /\ m.c = c /\ m.rid = creq[c]
  /\ ~\E n \in Lease : alive[n] /\ \E y \in rq[n] : y.c = c /\ y.rid = creq[c]
  /\ ~\E n \in Lease : alive[n] /\ role[n] = "L" /\ OwnEntry(n, x) /\ ~\E r \in gr : OwnDec(n, r, x)
\* derives: C1.4, F1.1, F1.2, F2.1, F2.2 -- a requester whose request is lost sends it again
\* (the timeout is abstracted: it fires once nothing of the request survives)
Retransmit(c) ==
  /\ alive[c] /\ ~paused[c] /\ creq[c] # 0 /\ ReqLost(c)
  /\ \E n \in Lease : alive[n] /\ Link(c, n) /\ (role[n] = "L" \/ Reach(n) # {})
  /\ Broadcast(c, creq[c], <<>>, creq)
  /\ <<rq', net', log', ctok'>> # <<rq, net, log, ctok>>
  /\ UNCHANGED <<dc, acc, srv, rqs, hiw, alive, inc, term, voted, role, cfgs, pend, cq, rag, rep, spur,
                 paused, stoV, down, opgot>>

\* derives: C1.3, C2.2, F1.1, F2.2 -- storage sends a reply it has decided (lost if storage crashed first)
SendOut(o) ==

  /\ sout' = sout \ {o}

DeliverWA(m) ==

DeliverRA(m) ==

\* derives: C3.4 -- an operator's reply (kept only to describe resends; replies arrive in the step they are sent)
RCA(n, x) == [ty |-> "rca", op |-> x.op, rid |-> x.rid, out |-> x.out, ep |-> x.ep, fr |-> n]
\* derives: C3.4, F1.2, F2.1, F2.2 -- receiver n's reply x reaches its operator in the step it is sent if n->op is up
\* (lost otherwise, and resent); the operator records the outcome once per request
OpRecv(n, x) ==
  IF Link(n, x.op) /\ x.rid \notin opgot[x.op]
  THEN [ev |-> <<[event |-> "ReconfigAck", proc |-> x.op, operator |-> x.op, request_id |-> x.rid,
                  outcome |-> x.out, epoch |-> x.ep, fr |-> n]>>,
        got |-> [opgot EXCEPT ![x.op] = @ \cup {x.rid}]]
  ELSE [ev |-> <<>>, got |-> opgot]
\* derives: C3.1, C3.4, F3.1 -- receiver n records request rid; invalid, then busy, are refused at once
RecvRC(n, op, rid, mem, ev0) ==
  LET rr == [event |-> "ReconfigRequest", proc |-> n, operator |-> op, request_id |-> rid, members |-> mem]
      invalid == mem = {} \/ ~(mem \subseteq Lease)
      busy == pend[n] # NoPend
      out == IF invalid THEN "invalid" ELSE "busy"
      x == [op |-> op, rid |-> rid, out |-> out, ep |-> -1]
      O == OpRecv(n, x)
  IN IF invalid \/ busy
     THEN /\ ev' = ev0 \o <<rr, EvRF(n, rid, mem, out, -1,
                                    IF invalid THEN [x_ \in {} |-> 0] ELSE [pending |-> pend[n].rid])>> \o O.ev
          /\ rep' = [rep EXCEPT ![n] = @ \cup {x}]
          /\ opgot' = O.got
          /\ UNCHANGED pend
     ELSE /\ ev' = ev0 \o <<rr>>
          /\ pend' = [pend EXCEPT ![n] = [op |-> op, rid |-> rid, mem |-> mem, tgt |-> Cur(n) + 1]]
          /\ UNCHANGED <<rep, opgot>>
\* derives: C3.4 -- the change a receiver holds, as passed on
PItem(n) == [rid |-> pend[n].rid, mem |-> pend[n].mem, tgt |-> pend[n].tgt, rcv |-> n, rinc |-> inc[n]]
\* derives: C3.4 -- the changes a leader holds (passed to it, or its own as receiver)
Items(n) == cq[n] \cup (IF pend[n] # NoPend THEN {PItem(n)} ELSE {})
\* derives: C3.1, C3.8 -- leader l may start change x now: the next epoch, one change at a time
CanProposeCfg(l, x) == role[l] = "L" /\ alive[l] /\ Cur(l) = x.tgt - 1 /\ UndecIdx(l) = {}
\* derives: C3.1, C3.8 -- leader l starts change x (its joint entry), or holds it until it can
GiveCfg(l, x) ==
  IF CanProposeCfg(l, x)
  THEN LET J == [k |-> "c", t |-> term[l], ep |-> x.tgt, mem |-> x.mem, rid |-> x.rid, rcv |-> x.rcv, rinc |-> x.rinc]
       IN /\ log' = [log EXCEPT ![l] = Append(@, J)]
          /\ ev' = <<EvAgree(l, inc[l], CProp(J))>>
          /\ cq' = [cq EXCEPT ![l] = @ \ {x}]
  ELSE /\ cq' = [cq EXCEPT ![l] = @ \cup {x}] /\ ev' = <<>> /\ UNCHANGED log
\* derives: C3.4, F2.1 -- leaders the receiver n reaches directly, or else through one member that reaches them
CfgTargets(n) ==
  LET D == {l \in Lease : l # n /\ role[l] = "L" /\ alive[l] /\ Link(n, l)}
      V == {l \in Lease : l # n /\ role[l] = "L" /\ alive[l] /\
              \E m \in MemOf(n, Cur(n)) \ {n, l} : alive[m] /\ Link(n, m) /\ Link(m, l)}
  IN IF D # {} THEN D ELSE V
\* derives: C3.4, F2.1 -- the receiver passes its pending request to a leader (in one step, as a client's request)
FwdCfg(n, l) ==
  /\ pend[n] # NoPend /\ alive[n] /\ l \in CfgTargets(n)
  /\ LET x == PItem(n) IN
     /\ x \notin cq[l] /\ x.tgt > Cur(l)
     /\ ~\E i \in CfgIdx(l) : log[l][i].rid = x.rid /\ log[l][i].rcv = n /\ log[l][i].rinc = inc[n]
     /\ GiveCfg(l, x)
  /\ UNCHANGED <<histV, alive, inc, term, voted, role, mi, cfgs, pend, rq, kb, agd, rag, rep, spur,
                 cliV, stoV, net, down, opgot>>
\* derives: C3.1, C3.8 -- a leader starts a change it holds once it can
ProposeCfg(l, x) ==
  /\ x \in Items(l) /\ CanProposeCfg(l, x)
  /\ ~\E i \in CfgIdx(l) : log[l][i].rid = x.rid /\ log[l][i].rcv = x.rcv /\ log[l][i].rinc = x.rinc
  /\ GiveCfg(l, x)
  /\ UNCHANGED <<histV, alive, inc, term, voted, role, mi, cfgs, pend, rq, kb, agd, rag, rep, spur,
                 cliV, stoV, net, down, opgot>>
\* derives: C3.1 -- node m learns the decided configurations in X it did not know
LearnEv(m, X) == LET E == SortSet(DOMAIN X \ DOMAIN cfgs[m])
                 IN [k \in 1..Len(E) |-> EvCC(m, E[k], X[E[k]], FALSE)]
\* derives: C3.1, C3.4
Merge(m, X) == cfgs[m] @@ X
\* derives: C3.8, F3.3 -- the agreements the receiver has been handed for its pending change
MyAtoms(r) == {a \in kb[r] : pend[r] # NoPend /\ a.j.rcv = r /\ a.j.rinc = inc[r]
                              /\ a.j.rid = pend[r].rid /\ a.j.ep = pend[r].tgt}
\* derives: C3.8, F3.3 -- eligibility in the requested set: re-admitted by an earlier commit
EligNewK(r, q, qi, mem, old) == q \in mem /\ (qi = 0 \/ <<q, qi>> \in Readm(r, old))
\* derives: C3.1, C3.4, C3.8, F3.3 -- the receiver records the agreements and decides once both majorities are eligible
Decide(r) ==
  /\ pend[r] # NoPend /\ alive[r]
  /\ LET p == pend[r]
         old == p.tgt - 1
         new == {[q |-> a.q, qi |-> a.qi] : a \in MyAtoms(r)} \ rag[r]
         R1 == rag[r] \cup new
         P == {<<x.q, x.qi>> : x \in R1}
         knows == old \in DOMAIN cfgs[r]
         okOld == knows /\ MajK(r, P, old)
         okNew == knows /\ 2 * Cardinality({x[1] : x \in {y \in P : EligNewK(r, y[1], y[2], p.mem, old)}})
                            > Cardinality(p.mem)
         ct(q, qi) == (IF knows /\ EligK(r, q, qi, old) THEN {old} ELSE {})
                      \cup (IF knows /\ EligNewK(r, q, qi, p.mem, old) THEN {p.tgt} ELSE {})
         ns == PairSeq({<<x.q, x.qi>> : x \in new})
         agreedEvs == [k \in 1..Len(ns) |-> EvAgreed(r, ns[k][1], ns[k][2],
                          [epoch |-> p.tgt, members |-> p.mem, request_id |-> p.rid], ct(ns[k][1], ns[k][2]))]
         rm == {x \in P : x[2] > 0 /\ x[1] \in p.mem}
         rec == [mem |-> p.mem, rid |-> p.rid, rm |-> rm]
         X == cfgs[r] @@ (p.tgt :> rec)
         reply == [op |-> p.op, rid |-> p.rid, out |-> "committed", ep |-> p.tgt]
         told == {m \in Lease \ {r} : alive[m] /\ Link(r, m)}
         dEv == EvCC(r, p.tgt, rec, TRUE) @@
                [inputs |-> [agreed |-> P, old_members |-> IF knows THEN MemOf(r, old) ELSE {}, old_epoch |-> old,
                             request_id |-> p.rid, requested_members |-> p.mem]]
         tl == NodeOrder(told)
     IN
     /\ new # {} \/ (okOld /\ okNew)
     /\ IF okOld /\ okNew
        THEN /\ cfgs' = [m \in Lease |-> IF m = r THEN X ELSE IF m \in told THEN Merge(m, X) ELSE cfgs[m]]
             /\ cq' = [m \in Lease |-> IF m \in told \cup {r}
                                       THEN {y \in cq[m] : y.tgt > SetMax(DOMAIN X \cup DOMAIN cfgs[m])}
                                       ELSE cq[m]]
             /\ dc' = dc \cup {[ep |-> p.tgt, mem |-> p.mem, rid |-> p.rid, rm |-> rm, d |-> r, di |-> inc[r]]}
             /\ pend' = [pend EXCEPT ![r] = NoPend]
             /\ rag' = [rag EXCEPT ![r] = {}]
             /\ rep' = [rep EXCEPT ![r] = @ \cup {reply}]
             /\ opgot' = OpRecv(r, reply).got
             /\ ev' = agreedEvs \o <<dEv>> \o OpRecv(r, reply).ev \o Flat([k \in 1..Len(tl) |-> LearnEv(tl[k], X)])
        ELSE /\ rag' = [rag EXCEPT ![r] = R1]
             /\ ev' = agreedEvs
             /\ UNCHANGED <<cfgs, cq, dc, pend, rep, opgot>>
  /\ UNCHANGED <<gr, acc, srv, rqs, lastG, hiw, alive, inc, term, voted, role, log, mi, rq, kb, agd, spur,
                 cliV, stoV, down, net>>
\* derives: C3.4 -- a receiver that learns the epoch its request would occupy committed elsewhere refuses it
Supersede(r) ==
  /\ pend[r] # NoPend /\ alive[r] /\ pend[r].tgt \in DOMAIN cfgs[r]
  /\ LET p == pend[r]
         reply == [op |-> p.op, rid |-> p.rid, out |-> "superseded", ep |-> p.tgt]
     IN /\ ev' = <<EvRF(r, p.rid, p.mem, "superseded", p.tgt, [commit |-> p.tgt])>> \o OpRecv(r, reply).ev
        /\ pend' = [pend EXCEPT ![r] = NoPend]
        /\ rag' = [rag EXCEPT ![r] = {}]
        /\ rep' = [rep EXCEPT ![r] = @ \cup {reply}]
        /\ opgot' = OpRecv(r, reply).got
  /\ UNCHANGED <<histV, alive, inc, term, voted, role, log, mi, cfgs, cq, rq, kb, agd, spur,
                 cliV, stoV, down, net>>
\* derives: C3.4, F2.1 -- agreements for a receiver: to it, or relayed by one node that reaches it when n does not
RelayAtoms(n, m) == {a \in kb[n] \ kb[m] : a.j.rcv # n /\
                       (m = a.j.rcv \/ (~Link(n, a.j.rcv) /\ Link(m, a.j.rcv)))}
\* derives: C3.1, C3.4 -- n tells m the decided configurations it knows, and relays agreements
Gossip(n, m) ==
  /\ n # m /\ alive[n] /\ alive[m] /\ Link(n, m)
  /\ (DOMAIN cfgs[n] \ DOMAIN cfgs[m] # {} \/ RelayAtoms(n, m) # {})
  /\ LET X == Merge(m, cfgs[n])
     IN /\ cfgs' = [cfgs EXCEPT ![m] = X]
        /\ cq' = [cq EXCEPT ![m] = {y \in @ : y.tgt > SetMax(DOMAIN X)}]
        /\ ev' = LearnEv(m, cfgs[n])
  /\ kb' = [kb EXCEPT ![m] = @ \cup RelayAtoms(n, m)]
  /\ UNCHANGED <<histV, alive, inc, term, voted, role, log, mi, pend, rq, agd, rag, rep, spur,
                 cliV, stoV, net, down, opgot>>
\* derives: C3.4, F1.2, F2.1 -- the receiver resends a reply that has not reached its operator
Resend(r, x) ==
  /\ x \in rep[r] /\ alive[r] /\ x.rid \notin opgot[x.op] /\ Link(r, x.op)
  /\ ev' = OpRecv(r, x).ev
  /\ opgot' = OpRecv(r, x).got
  /\ UNCHANGED <<histV, alive, inc, term, voted, role, log, mi, cfgs, pend, cq, rq, kb, agd, rag, rep, spur,
                 cliV, stoV, net, down>>

\* derives: F1.1, F1.2, F1.3, F2.1, F2.2, F3.1, F3.2, F3.3, C1.1, C1.2, C2.1 -- take step pc's action
DoAct(a) ==
  \/ /\ a.a = "request"
     /\ LET c == Res(a.c) IN
        /\ c \in Clients /\ alive[c] /\ ~paused[c] /\ creq[c] = 0
        /\ Broadcast(c, pc, <<[event |-> "Request", proc |-> c, client |-> c, key |-> KeyName, rid |-> pc]>>,

     /\ LET c == Res(a.c)
            hi == MaxGranted
            st == {t \in ctoks[c] : t.tok < hi}

                      /\ ev' = <<[event |-> "WriteAttempt", proc |-> c, client |-> c, key |-> KeyName, token |-> t.tok,

                 ELSE /\ net' = net \cup Send(c, [ty |-> "r", c |-> c, tok |-> t.tok, gt |-> t.gt, id |-> pc])

     /\ UNCHANGED <<ngc, histV, alive, inc, term, voted, role, log, mi, cfgs, pend, cq, rq, kb, agd, rag, rep, spur,
                    cliV, stoV, down, opgot>>
  \/ /\ a.a = "crash"

  \/ /\ a.a = "restart"

     /\ UNCHANGED <<ngc, histV, spur, down, opgot>>

             /\ ev' = <<[event |-> "Fault", proc |-> "env", cell |-> a.cell, partition |-> <<A, B>>, links |-> L]>>
     /\ UNCHANGED <<ngc, histV, alive, inc, term, voted, role, log, mi, cfgs, pend, cq, rq, kb, agd, rag, rep, spur,

  \/ /\ a.a \in {"cut", "drop"}

          IN /\ (ng = "none") = (\A i \in 1..Len(a.links) : "non-grantor" \notin {a.links[i][1], a.links[i][2]})
             /\ down' = down \cup L
             /\ ev' = <<[event |-> "Fault", proc |-> "env", cell |-> a.cell, links |-> L]>>
     /\ UNCHANGED <<ngc, histV, alive, inc, term, voted, role, log, mi, cfgs, pend, cq, rq, kb, agd, rag, rep, spur,
                    cliV, stoV, net, opgot>>
  \/ /\ a.a = "heal"
     /\ down' = {}
     /\ ev' = <<[event |-> "Fault", proc |-> "env", cell |-> a.cell, heal |-> TRUE, links |-> {}]>>
     /\ UNCHANGED <<ngc, histV, alive, inc, term, voted, role, log, mi, cfgs, pend, cq, rq, kb, agd, rag, rep, spur,

  \/ /\ a.a = "pause"

     /\ UNCHANGED <<ngc, histV, alive, inc, term, voted, role, log, mi, cfgs, pend, cq, rq, kb, agd, rag, rep, spur,

  \/ /\ a.a = "resume"
     /\ LET c == Res(a.c) IN
        /\ c \in Clients /\ paused[c]
        /\ paused' = [paused EXCEPT ![c] = FALSE]
        /\ ev' = <<[event |-> "Fault", proc |-> "env", cell |-> "F1.3", resume |-> c]>>
     /\ UNCHANGED <<ngc, histV, alive, inc, term, voted, role, log, mi, cfgs, pend, cq, rq, kb, agd, rag, rep, spur,
                    ctok, ctoks, creq, stoV, net, down, opgot>>
  \/ /\ a.a = "reconf"
     /\ \E to \in (CASE a.to = "non-grantor" -> snap.upL \ {snap.g}
                     [] a.to = "non-member" -> snap.nm
                     [] OTHER -> {Res(a.to)}) :
          /\ to \in Lease
          /\ LET ev0 == <<[event |-> "ReconfigSend", proc |-> a.op, operator |-> a.op, request_id |-> a.rid,
                           to |-> to, members |-> a.mem]>>
             IN IF alive[to] /\ Link(a.op, to) THEN RecvRC(to, a.op, a.rid, a.mem, ev0)
                ELSE ev' = ev0 /\ UNCHANGED <<pend, rep, opgot>>
     /\ rqs' = rqs \cup {[rid |-> a.rid, mem |-> a.mem]}
     /\ UNCHANGED <<ngc, gr, dc, acc, srv, lastG, hiw, alive, inc, term, voted, role, log, mi, cfgs, cq, rq, kb,
                    agd, rag, spur, cliV, stoV, down, net>>
  \/ /\ a.a = "clock"
     /\ LET p == IF a.p = "non-grantor" THEN ngc ELSE Res(a.p) IN
        /\ p \in Procs
        /\ ev' = <<[event |-> "Fault", proc |-> "env", cell |-> "F3.2", clock |-> p, step |-> a.step, ticks |-> a.ticks]>>
     /\ UNCHANGED <<ngc, histV, alive, inc, term, voted, role, log, mi, cfgs, pend, cq, rq, kb, agd, rag, rep, spur,
                    cliV, stoV, net, down, opgot>>

\* derives: C1.1 -- (c) in every log, decided grants appear in increasing token order (a node agrees in log order)

#!/usr/bin/env python3
"""Schedule compiler: testbed/schedules/<name>.yaml -> a TLC configuration for Lease.tla.

derives: F1.1, F1.2, F1.3, F2.1, F2.2, F3.1, F3.2, F3.3, C1.4, C3.4
(every cell's action is compiled into the environment step it enables; the end trigger and the last fault feed the
liveness premises of C1.4 and C3.4)

usage: compile.py <schedule.yaml> <outdir> [--module Lease] [--max-term N] [--spur N]
Writes <outdir>/MC.tla (constants), safety.cfg, witness.cfg, live.cfg, and meta.json (bounds and reach facts).
Rejects, with exit status 2 and a reason, any schedule the format (v2.2 to v5) does not allow.
"""
import json
import os
import sys
from fractions import Fraction

import yaml

# derives: F1.1, F1.2, F1.3, F2.1, F2.2, F3.1, F3.2, F3.3 -- the cells and the action each one allows
CELLS = {'F1.1': {'crash', 'restart'}, 'F1.2': {'partition', 'heal'}, 'F1.3': {'pause', 'resume'},
         'F2.1': {'cut', 'heal'}, 'F2.2': {'drop', 'heal'}, 'F3.1': {'reconfigure'}, 'F3.2': {'clock'},
         'F3.3': {'restart'}}
SELECTORS = {'grantor', 'holder', 'non-grantor', 'non-member', 'rest'}
FAULTS = {'crash', 'restart', 'partition', 'cut', 'drop', 'pause', 'resume', 'clock'}  # heal and reconfigure are not


class Reject(Exception):
    """derives: F1.1 -- a schedule the format does not allow"""


def tla(v):
    """derives: F3.1 -- a Python value as a TLA+ constant expression"""
    if isinstance(v, bool):
        return 'TRUE' if v else 'FALSE'
    if isinstance(v, int):
        return str(v)
    if isinstance(v, str):
        return '"' + v.replace('"', '\\"') + '"'
    if isinstance(v, (set, frozenset)):
        return '{' + ', '.join(tla(x) for x in sorted(v, key=str)) + '}'
    if isinstance(v, tuple):
        return '<<' + ', '.join(tla(x) for x in v) + '>>'
    if isinstance(v, list):
        return '<<' + ', '.join(tla(x) for x in v) + '>>'
    if isinstance(v, dict):
        if not v:
            return '[x_ \\in {} |-> 0]'
        return '[' + ', '.join(f'{k} |-> {tla(x)}' for k, x in v.items()) + ']'
    raise Reject(f'cannot express {v!r}')


def compile_schedule(sched, max_term=None, spur=None):
    """derives: F1.1, F1.2, F1.3, F2.1, F2.2, F3.1, F3.2, F3.3 -- returns (constants, meta) or raises Reject"""
    procs = sched.get('processes') or {}
    lease = list(procs.get('lease') or [])
    clients = list(procs.get('clients') or [])
    storage = list(procs.get('storage') or [])
    config = list(procs.get('config') or lease)
    ops = list(procs.get('operators') or ['op'])
    if not lease or len(lease) > 6:
        raise Reject('lease must name one to six nodes')
    if len(storage) != 1:
        raise Reject('exactly one storage process (contract v3)')
    if not set(config) <= set(lease) or not config:
        raise Reject('config must be a non-empty subset of lease')
    names = lease + clients + storage + ops
    if len(set(names)) != len(names):
        raise Reject('process names must be distinct')
    if any(n in SELECTORS or n == 'env' for n in names):
        raise Reject('a process may not be named like a selector')
    life = sched.get('lifetime', 1)
    if not isinstance(life, int) or life < 1:
        raise Reject('lifetime must be a positive whole number of ticks')
    S = storage[0]
    crashed = set()
    paused = set()
    steps = []
    meta = {'requests': 0, 'grant_steps': 0, 'crashes': 0, 'restarts': 0, 'amnesic': 0, 'clock_steps': [],
            'reconfigs': 0, 'partitions': 0, 'links': 0, 'leader_faults': 0, 'writes': 0, 'reads': 0}
    rids = []
    last_fault = 0
    seen_request = False
    crashed_ng = False

    def proc(x, kinds, where):
        """derives: F1.1, F3.1 -- Rule A1: a process name or an allowed selector in this position"""
        if x in ('grantor', 'holder') and not seen_request:
            raise Reject(f'{where}: {x} used before any Grant can have occurred')
        if x == 'grantor' and 'lease' not in kinds:
            raise Reject(f'{where}: grantor is a lease node')
        if x == 'holder' and 'client' not in kinds:
            raise Reject(f'{where}: holder is a client')
        if x in ('grantor', 'holder', 'non-grantor'):
            if x == 'non-grantor' and 'lease' not in kinds:
                raise Reject(f'{where}: non-grantor is a lease node')
            return x
        ok = (('lease' in kinds and x in lease) or ('client' in kinds and x in clients) or
              ('storage' in kinds and x == S) or ('op' in kinds and x in ops))
        if not ok:
            raise Reject(f'{where}: {x!r} is not an allowed process here')
        return x

    def trigger(t, where):
        """derives: F1.1 -- Rule T1: start or an event trigger with field filters"""
        if t == 'start':
            return {'kind': 'start'}
        if not isinstance(t, dict) or 'event' not in t:
            raise Reject(f'{where}: a trigger is start or {{event: ...}}')
        f = {}
        for k, v in t.items():
            if k == 'event':
                continue
            if k == 'members':
                v = frozenset(v)
            f[k] = v
        return {'kind': 'ev', 'event': t['event'], 'f': f}

    raw_steps = sched.get('steps') or []
    meta['leader_losses'] = 0
    prev_crash = False
    for st in raw_steps:
        d = st.get('do') or {}
        is_crash = 'crash' in d and (d['crash'] in lease or d['crash'] in ('grantor', 'non-grantor'))
        if is_crash and not prev_crash:
            meta['leader_losses'] += 1
        if any(k in d for k in ('partition', 'cut', 'drop')):
            meta['leader_losses'] += 1
        prev_crash = is_crash or (prev_crash and 'crash' in d)
    if any('reconfigure' in (st.get('do') or {}) for st in raw_steps):
        meta['leader_losses'] += 1
    for i, st in enumerate(raw_steps, start=1):
        where = f'step {i}'
        at = trigger(st.get('at'), where)
        do = st.get('do') or {}
        cell = do.get('cell')
        a = None
        if 'request' in do:
            c = proc(do['request'], {'client'}, where)
            a = {'a': 'request', 'c': c}
            seen_request = True
            meta['requests'] += 1
        elif 'write' in do or 'read' in do:
            kind = 'write' if 'write' in do else 'read'
            c = proc(do[kind], {'client'}, where)
            tok = do.get('token')
            if tok not in (None, 'stale'):
                raise Reject(f'{where}: token is stale or absent')
            a = {'a': kind, 'c': c, 'v': str(do.get('value', '')) if kind == 'write' else '', 'stale': tok == 'stale'}
            if kind == 'write' and 'value' not in do:
                raise Reject(f'{where}: a write names a value')
            meta['writes' if kind == 'write' else 'reads'] += 1
        elif cell is None:
            raise Reject(f'{where}: unknown action {do!r}')
        else:
            if cell not in CELLS:
                raise Reject(f'{where}: no cell {cell} in the failure model')
            verb = next((k for k in do if k != 'cell' and k not in ('to', 'id', 'operator', 'step', 'amnesia')), None)
            if verb == 'heal' and cell in ('F1.2', 'F2.1', 'F2.2'):
                a = {'a': 'heal', 'cell': cell}
            elif verb not in CELLS[cell]:
                raise Reject(f'{where}: {cell} has no action {verb!r}')
            elif verb == 'crash':
                p = proc(do['crash'], {'lease', 'client', 'storage'}, where)
                if p in crashed:
                    raise Reject(f'{where}: crash of a process already crashed')
                if p not in SELECTORS:
                    crashed.add(p)
                if p == 'non-grantor':
                    crashed_ng = True
                a = {'a': 'crash', 'p': p, 'cell': cell}
                meta['crashes'] += 1
                if p in ('grantor',) or p in lease or p == 'non-grantor':
                    meta['leader_faults'] += 1
            elif verb == 'restart' and do.get('amnesia'):
                if cell != 'F3.3':
                    raise Reject(f'{where}: amnesia is F3.3')
                p = do['restart']
                if p == 'non-grantor':
                    if not crashed_ng:
                        raise Reject(f'{where}: restart non-grantor without an earlier crash non-grantor')
                else:
                    p = proc(p, {'lease'}, where)
                    if p not in SELECTORS and p not in crashed:
                        raise Reject(f'{where}: amnesic restart of a process that is not crashed')
                    crashed.discard(p)
                a = {'a': 'amnesia', 'p': p}
                meta['amnesic'] += 1
            elif verb == 'restart':
                if cell != 'F1.1':
                    raise Reject(f'{where}: restart is F1.1 (or F3.3 with amnesia)')
                p = do['restart']
                if p == 'non-grantor':
                    if not crashed_ng:
                        raise Reject(f'{where}: restart non-grantor without an earlier crash non-grantor')
                else:
                    p = proc(p, {'lease', 'client', 'storage'}, where)
                    if p not in SELECTORS and p not in crashed:
                        raise Reject(f'{where}: restart of a process that is not crashed')
                    crashed.discard(p)
                a = {'a': 'restart', 'p': p, 'cell': cell}
                meta['restarts'] += 1
            elif verb == 'partition':
                sides = do['partition']
                if not (isinstance(sides, list) and len(sides) == 2):
                    raise Reject(f'{where}: a partition has two sides')
                conv = []
                for side in sides:
                    sset = set()
                    for x in side:
                        if x == 'rest':
                            sset.add('rest')
                        else:
                            sset.add(proc(x, {'lease', 'client', 'storage', 'op'}, where))
                    conv.append(frozenset(sset))
                if 'rest' in conv[0] and 'rest' in conv[1]:
                    raise Reject(f'{where}: rest on both sides')
                a = {'a': 'partition', 's1': conv[0], 's2': conv[1], 'cell': cell}
                meta['partitions'] += 1
                meta['leader_faults'] += 1
            elif verb in ('cut', 'drop'):
                pairs = do[verb]
                lk = []
                for pr in pairs:
                    if len(pr) != 2 or 'rest' in pr:
                        raise Reject(f'{where}: a link is a pair of processes or selectors (not rest)')
                    lk.append(tuple(proc(x, {'lease', 'client', 'storage', 'op'}, where) for x in pr))
                a = {'a': verb, 'links': lk, 'cell': cell}
                meta['links'] += len(lk)
                meta['leader_faults'] += 1
            elif verb in ('pause', 'resume'):
                c = proc(do[verb], {'client'}, where)
                if verb == 'pause' and c in paused:
                    raise Reject(f'{where}: pause of a paused client')
                if verb == 'resume' and c not in paused and c not in SELECTORS and 'holder' not in paused:
                    raise Reject(f'{where}: resume of a running client')
                (paused.add if verb == 'pause' else paused.discard)(c)
                a = {'a': verb, 'c': c}
            elif verb == 'reconfigure':
                mem = do['reconfigure']
                if not isinstance(mem, list):
                    raise Reject(f'{where}: reconfigure lists members')
                if any(m in SELECTORS for m in mem):
                    raise Reject(f'{where}: members are process names, not selectors')
                to = do.get('to')
                if to in ('non-grantor', 'non-member'):
                    pass
                else:
                    to = proc(to, {'lease'}, where)
                rid = do.get('id')
                if rid is None or rid in rids:
                    raise Reject(f'{where}: request id missing or not unique')
                op = do.get('operator', 'op')
                if op not in ops:
                    raise Reject(f'{where}: operator {op!r} not declared')
                rids.append(rid)
                a = {'a': 'reconf', 'mem': frozenset(str(m) for m in mem), 'to': to, 'rid': str(rid), 'op': op}
                meta['reconfigs'] += 1
            elif verb == 'clock':
                p = proc(do['clock'], {'lease', 'client', 'storage', 'op'}, where)
                step = Fraction(str(do.get('step')))
                if (step * life).denominator != 1:
                    raise Reject(f'{where}: step x lifetime must be a whole number of ticks')
                a = {'a': 'clock', 'p': p, 'step': str(do.get('step')), 'ticks': int(step * life)}
                meta['clock_steps'].append(int(step * life))
            else:
                raise Reject(f'{where}: unknown action')
            if a['a'] in FAULTS or a['a'] == 'amnesia':
                last_fault = i
        steps.append({'at': at, 'do': a})

    end = sched.get('end', 'quiescent')
    endt = {'kind': 'quiescent'} if end == 'quiescent' else trigger(end, 'end')
    # derives: C1.1, C1.4 -- reach-driven bounds: one term per election the schedule can force, plus slack
    if spur is None:
        spur = 1
    if max_term is None:
        max_term = 1 + meta['leader_losses'] + spur
    const = {
        'LeaseSeq': tuple(lease), 'Clients': frozenset(clients), 'S': S, 'Ops': frozenset(ops),
        'InitCfg': frozenset(config), 'Life': life, 'KeyName': 'k', 'Steps': [_step(s) for s in steps],
        'EndT': _trig(endt), 'LastFault': last_fault, 'ReqIds': frozenset(rids),
        'MaxTerm': max_term, 'Spur0': spur,
    }
    meta.update({'name': sched.get('schedule'), 'last_fault': last_fault, 'max_term': max_term, 'spur': spur,
                 'n_steps': len(steps), 'end': end, 'lease': lease, 'config': config, 'clients': clients,
                 'storage': S, 'operators': ops, 'lifetime': life, 'request_ids': rids})
    return const, meta


def _trig(t):
    """derives: F1.1 -- a trigger record with a uniform shape"""
    if t['kind'] in ('start', 'quiescent'):
        return {'kind': t['kind'], 'event': '', 'f': {}}
    return {'kind': 'ev', 'event': t['event'], 'f': t['f']}


def _step(s):
    """derives: F1.1"""
    return {'at': _trig(s['at']), 'do': s['do']}


def write_outputs(const, meta, outdir, module='Lease'):
    """derives: C1.1, C1.2, C1.3, C1.4, C2.1, C2.2, C3.1, C3.4, C3.5, C3.7, C3.8 -- the TLC configurations"""
    os.makedirs(outdir, exist_ok=True)
    lines = ['---- MODULE MC ----', f'EXTENDS {module}, TLC']
    for k, v in const.items():
        lines.append(f'MC_{k} == {tla(v)}')
    lines.append('====')
    open(os.path.join(outdir, 'MC.tla'), 'w').write('\n'.join(lines) + '\n')
    consts = '\n'.join(f'  {k} <- MC_{k}' for k in const)
    inv = ['C1_1_Tokens', 'C1_1_AgreeOrder', 'C1_1_Terms', 'C3_1']
    steps = ['C1_2_Step', 'C1_3_Step', 'C2_1_Step', 'C2_2_Step', 'C3_1_Step', 'C3_7_Step', 'C3_8_Step', 'C3_5_Step']
    common = f'CONSTANTS\n{consts}\nCHECK_DEADLOCK FALSE\nVIEW View\n'
    open(os.path.join(outdir, 'safety.cfg'), 'w').write(
        common.replace('CHECK_DEADLOCK FALSE', 'CHECK_DEADLOCK TRUE') + 'SPECIFICATION SpecL\nINVARIANTS\n' + ''.join(f'  {x}\n' for x in inv) +
        'PROPERTIES\n' + ''.join(f'  {x}\n' for x in steps))
    open(os.path.join(outdir, 'witness.cfg'), 'w').write(common + 'SPECIFICATION Spec\nINVARIANT NotEnded\n')
    props = ['C1_4'] + (['C3_4_Resolved', 'C3_4_Told'] if const['ReqIds'] else [])
    open(os.path.join(outdir, 'live.cfg'), 'w').write(
        common + 'SPECIFICATION LiveSpec\nPROPERTIES\n' + ''.join(f'  {x}\n' for x in props))
    json.dump(meta, open(os.path.join(outdir, 'meta.json'), 'w'), indent=1, default=str)


def main(argv):
    """derives: F1.1 -- command line: compile one schedule"""
    args = list(argv)
    module, max_term, spur = 'Lease', None, None
    while args and args[0].startswith('--'):
        flag = args.pop(0)
        if flag == '--module':
            module = args.pop(0)
        elif flag == '--max-term':
            max_term = int(args.pop(0))
        elif flag == '--spur':
            spur = int(args.pop(0))
        else:
            print(f'unknown flag {flag}', file=sys.stderr)
            return 2
    if len(args) != 2:
        print(__doc__, file=sys.stderr)
        return 2
    try:
        sched = yaml.safe_load(open(args[0]))
        const, meta = compile_schedule(sched, max_term, spur)
    except Reject as e:
        print(f'REJECTED {e}', file=sys.stderr)
        return 2
    write_outputs(const, meta, args[1], module)
    return 0


if __name__ == '__main__':
    sys.exit(main(sys.argv[1:]))
